# RainFX v2 — 부착 물방울 형태의 다양성: 실제 사례 조사와 구현 비용 (2026-10-27)

요청(사용자, rev39 컨펌 후): 물방울의 기본 굴절·경계면 작업을 완료한다. 단계 1을 마치기 위해, 표면에 붙은 물방울의 다양한 형태를
실제 사례를 기반으로 조사하고, 그 다양성을 구현하는 비용을 계산한다.

## 1. 기준 영상에서 보이는 형태 (`ref_OBJECTIVES/…물방울형태및흐름…mp4`, 1·4·8 s 프레임)

확대 이미지: `docs/prototypes/rainfx2_ref_shape_classes.png`. 아래 비율은 확대 구역 하나를 눈으로 센 대략값이다(측정이 아님).

| # | 형태 | 비율(대략) | 모습 | 물리적 원인 |
|---|---|---|---|---|
| F1 | 작은 둥근 방울 | ~60 % | 한쪽 초승달, 나머지는 배경에 녹음 | 정지 부착, 반지름 < 0.5 mm, 중력 무시(Bo ≪ 1) |
| F2 | 흐름 방향으로 긴 타원 | ~15 % | 길이/폭 1.3–2, 앞쪽 초승달이 굵음 | 미끄러지는 방울: 앞은 전진각, 뒤는 후퇴각 |
| F3 | **갈고리·쉼표(J, ?, ʃ)** | ~10 % (중·대형에서 두드러짐) | 몸통 + 휘어진 꼬리, 초승달이 꼬리까지 이어짐 | 미끄러지는 방울의 경로가 휘어서(지그재그·바람 방향 변화) 뒤쪽 접촉선이 옛 경로에 고정된 채 남음 |
| F4 | 합쳐진 불규칙 덩어리(땅콩, S자) | ~5 % | 두 원이 이어진 윤곽, 오목한 허리 | 합체 직후 접촉선이 이력현상으로 고정되어 원으로 돌아가지 못함 |
| F5 | 크고 납작한 방울 | 소수 | 넓고 밝은 내부, 한쪽만 굵은 테 | 반지름이 모세관 길이(2.7 mm)에 가까워 위가 평평해짐(Bo ≈ 0.3–0.6) |
| F6 | 짧은 가는 줄(streak) | 소수 | 흐름 방향의 얇은 어두운 선 | 흐른 자리에 남은 얇은 줄기(rivulet) |
| F7 | 점렬(작은 방울이 줄지어 남음) | 흐르는 방울 뒤 | 크기가 고른 점들 | pearling: 꼬리가 끊겨 위성 방울을 남김 |

F6·F7은 단계 3(trail·휩쓸기)의 범위이고, 이 문서는 F1–F5(방울 하나의 형태)를 다룬다.

## 2. 물리 근거

- **미끄러지는 방울의 형태 전이**
  - 경사판 위 방울은 속도(모세관수 Ca)가 커지면 둥근 형태 → 뒤쪽에 모서리(corner)가 생긴 형태 → 모서리 끝에서 작은 방울을 떨어뜨리는 pearling 순서로 바뀐다.
  - 앞쪽은 계속 둥글다. 모서리의 반각은 Ca가 클수록 작아진다.
  - 출처: [Le Grand, Daerr, Limat, JFM 2005](https://labo.msc.u-paris.fr/~daerr/reprints/Le-Grand-et-al_Shape-of-drops_JFM2005.pdf), [Limat et al.](https://labo.msc.u-paris.fr/~daerr/reprints/Limat-et-al_Drops-Exp-vs-Model_ProcECS2003.pdf), [Snoeijer et al., cornered contact lines](https://labo.msc.u-paris.fr/~daerr/reprints/Snoeijer-et-al_cornered-cl-instabilities_CANCAM2011.pdf)
  - F2(타원)와 F3·F7의 뿌리다.
- **고정된 방울(접촉각 이력현상)**
  - 경사면에 고정된 방울은 아래쪽이 전진각, 위쪽이 후퇴각이 되어 알 모양이 된다.
  - 표면 불균일(결함)에 접촉선이 걸리면 윤곽이 원에서 벗어난다.
  - 출처: [Droplets on inclined plates: local and global hysteresis](https://arxiv.org/pdf/1407.7212), [Pinning of a drop by a junction on an incline](https://arxiv.org/pdf/1707.06061)
  - F4가 원으로 돌아가지 못하는 이유이기도 하다. 합체 후 넓어진 접촉선은 후퇴각 아래로 줄어들 때까지 그대로 남는다.
- **바람과 중력을 함께 받는 방울**
  - 바람 방향으로 기울고 늘어나다가 떨어진다(depinning).
  - 떨어지기 직전에는 바람 방향 뒤쪽이 얇아진다.
  - 출처: [Wind- and gravity-forced drop depinning](https://ar5iv.labs.arxiv.org/html/2009.04059), [Waterloo 학위논문, wall-bounded shear flow](https://uwspace.uwaterloo.ca/handle/10012/16820)
  - rev20의 흔들림(wobble)과 rev24의 처짐(sag)이 이 범주다.
- **중력에 의한 납작함**
  - Bo = (R / 2.7 mm)²이다.
  - R ≈ 1 mm(Bo ≈ 0.14)까지는 구면 캡이다.
  - 그보다 크면 위가 평평해지고 테 쪽이 가팔라진다.
  - 출처: [capillary length](https://en.wikipedia.org/wiki/Capillary_length), [pancake 한계의 sessile drop, JFM 2023](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/C7447E3C86D39EE26D27C5F853128BE8/S0022112023002434a_hi.pdf/shape-of-sessile-drops-in-the-large-bond-number-pancake-limit.pdf)
  - 바이저 방울(R ≤ 2 mm, Bo ≤ 0.55)에서 F5가 가장 큰 방울에만 약하게 나타나는 이유다.

## 3. 현재 v2가 가진 다양성 (rev39)

| 요소 | 구현 | 한계 |

| 미끄럼 물방울 꼬리 | 뒤쪽 절반 늘이기(c.k) | 꼬리가 항상 직선이고 끝이 둥글다. 모서리와 휜 꼬리가 없다. |
| 처짐 | 큰 방울을 중력 반대로 늘임 | — |
| 흔들림 | 바람 속 고정 방울 | — |
| 접촉각 | 방울별 + 뒤쪽 후퇴 + 젖은 면 평탄화 | 위·아래 비대칭(전진/후퇴)은 미끄러질 때만 있다. |
| 합체 | 부피 합산 후 원으로 즉시 복귀 | 합체 모양 기억(F4)이 없다. |

사용자 스크린샷(rev39 측면·정면)과 비교하면, 방울이 모두 원·타원이라 기준 영상의 갈고리(F3)와 합체 덩어리(F4)가 빠져 있는 것이 가장 큰 차이다.

## 4. 구현 후보와 비용

### 4.1 비용 측정 방법

- 그리기 셰이더에 F2–F5용 형태 코드를 시제품으로 넣었다(배포 안 함, 스크래치 복사본).
  - 넣은 것: 윤곽 모드 n = 3·4, 뒤쪽 모서리, Bond 납작함, 방향별 접촉각.
  - 모든 항은 해석적 기울기(G)를 포함하므로 렌즈와 그대로 맞물린다.
- DXC(ps_6_0) DXIL 명령 수를 비교했다.

| 변형 | 셰이더 전체 정적 명령 수 | 차이 |
|---|---|---|
| rev39 기준 | 5 721 | — |
| 윤곽 모드만 | 6 053 | +332 |
| 네 가지 모두 | 6 187 | **+466** |

- 방울 커널은 셰이더 안에 5벌 있다(일반 1벌 + D-A 탭 4벌, D-A는 aperture > 0일 때만 실행).
- 따라서 방울 평가 1회당 **약 +93 명령**이다.
- 픽셀당 실제 평가 횟수는 도달 범위 안의 후보 수(대략 0.6–1.0회, 폭우 기준)다.

### 4.2 GPU 시간 추정 (RTX 3070, 출력 3240×1823, 바이저 ~85 % = 약 500만 픽셀)

- 계산: 500만 px × 1회 × 93 명령 ≈ 4.7억 lane-명령. 3070은 약 11 G lane-명령/ms를 처리한다.
- 이상적인 경우 **0.04 ms**, 분기·점유율 손실을 2–3배로 보면 **0.08–0.12 ms**다.
- 현재 draw 0.32–0.7 ms(EVAL §13–§18) 대비 **+10–20 %**다.
- 형태 상태 텍스처를 읽는 비용(아래 S2)은 후보당 Load 1회로, 기존 25회 대비 작다. 약 +0.01–0.03 ms다.

### 4.3 형태별 비용

| 우선 | 형태 | 방법 | 상태 | GPU(draw) | 시뮬 | 위험 |
|---|---|---|---|---|---|---|
| **P0** | 시드 16 → 64종 | 이동량 양자화 1/62.5 → 1/31.25 셀(±8셀 범위 유지). 남는 2비트를 시드로 쓴다. | 없음(재배치) | 0 | 0 | 늘이기 정밀도 0.037 mm/프레임. 화면에서는 구분되지 않는다. |
| **P1** | F3 갈고리 + 뒤쪽 모서리(F2) | 꼬리 쪽 좌표를 직전 경로 곡률로 휨: b' = b − κa²(a < 0). 모서리: d² = a² + (\|b\| + k_c\|a\|)², Ca 문턱 위에서만. | **S2** 필요: 평활된 이전 이동 방향 | ~+25 명령/평가, +1 Load | cells 추종 패스 | 꼬리 길이는 단계 3의 trail과 같은 규칙으로 맞춰야 한다. |
| **P2** | F4 합체 기억 | 합체 축 방향 늘이기(두 반지름 비로 크기 결정). 후퇴 조건(부피 감소·미끄럼)에서 서서히 원으로 돌아온다. 합체 직후 0.1 s 감쇠 진동. | **S2**: 늘이기 축·양·경과 시간 | ~+20 명령 | merge 추종 패스 | 진동은 흔들림 코드를 재사용한다. |
| P3 | F5 납작함 | h = 1 − (1−β)x − βx², β ∝ Bo(R > 1 mm에서 시작) | 없음 | ~+15 명령 | 0 | 굴절 내부/림 비율이 바뀐다. `Interior refraction` 재확인 필요. |
| P4 | 위·아래 접촉각 비대칭(고정 방울) | θ(φ) = θ₀ + Δθ·(e·중력/기류 방향) | 없음 | ~+12 명령(sin 1회) | 0 | 초승달의 한쪽 쏠림이 강해진다. 렌즈가 이미 한쪽 초승달을 만들므로 효과는 작다. |
| P5 | 윤곽 모드 n = 3·4 | f(φ) = 1 + a₃cos3φ + a₄cos4φ, 진폭 3–6 % | 없음(시드만) | ~+40 명령 | 0 | **rev17 윤곽 노이즈가 "기름 느낌"으로 불합격.** 기준 영상의 고정 방울도 원·타원이 대부분이라 보류를 권한다. |

### 4.4 S2 (방울 형태 상태 텍스처)

- **형식:** RGBA16F 512×128 = **512 KB**. 정수 2048까지 정확하다.
  - x = 시드(11비트로 확장 가능. 그러면 P0은 S2 도입 시 대체된다)
  - y = 평활 이전 방향 각도
  - z = 합체 늘이기 양 + 축
  - w = 합체 경과 시간
- **패스:** 방울은 cells·merge 패스에서 셀을 옮겨 다닌다. S2도 같은 선택(가장 큰 부피 방울)을 따라가야 하므로, 같은 5×5 수집을 하는 **추종 패스 2개**(cells 뒤, merge 뒤)가 서브스텝마다 추가된다.
  - GPU: 6.5만 텍셀 × 50 Load ≈ 서브스텝당 0.01–0.02 ms, 서브스텝 최대 4회면 **≤ 0.08 ms**.
  - CPU: Lua 패스 호출 2회/서브스텝. 측정 전에는 0.02–0.05 ms/회로 가정한다.
  - CSP ui.fx 패스가 여러 렌더 타깃(MRT)에 한 번에 쓸 수 있으면 추종 패스 없이 cells·merge 출력에 합칠 수 있다. preview728에서 가능한지는 구현 시 확인한다.

### 4.5 합계

| 묶음 | 내용 | 추가 비용(추정) |
|---|---|---|
| A (최소) | P0 + P3 + P4 | draw +0.02–0.04 ms, VRAM 0, 패스 0 |
| **B (권장)** | A + P1 + P2 (S2 포함) | draw +0.06–0.10 ms, 시뮬 +0.02–0.08 ms, CPU +0.04–0.4 ms(서브스텝 1–4), VRAM +512 KB |
| C (전부) | B + P5 | draw +0.10–0.15 ms |

- 추정치는 정적 명령 수 기반이다. 구현 후 Render Stats와 metrics로 실측한다(EVAL 방식).
- D-A(aperture > 0)를 켜면 커널이 4번 더 돌아 형태 비용이 최대 5배가 된다. 그래서 단계 4 디포커스는 별도 캔버스 방식(a)이 유리하다는 기존 판단이 더 강해진다.

## 5. 권장 순서와 검증

1. **P0 → P3 → P4** (묶음 A, rev40)
   - 상태 변경 없이 바로 확인할 수 있다.
   - 확인할 것: Look lab에서 큰 방울의 내부가 넓어지는지, 같은 모양 반복이 줄어드는지.
2. **S2 + P1 갈고리·모서리** (rev41)
   - 기준 영상과 가장 다른 부분이다.
   - 확인할 것: 미끄러지는 중·대형 방울의 갈고리 비율(기준 ~10 %).
3. **P2 합체 기억** (rev42)
   - 단계 3의 휩쓸어 합치기와 직접 이어진다.
4. P5는 사용자 판단 전까지 보류한다.
