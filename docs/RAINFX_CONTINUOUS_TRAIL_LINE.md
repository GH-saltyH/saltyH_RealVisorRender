# 연속 트레일 선분 표현: 끝부분 중복과 샘플링 분리

2026-10-25. 표시용 HLSL/CPU 구현과 실제 경로 비교 완료. **게임 실행 경로에는 아직 연결하지 않았다.**
물리32Hz, 방울 질량/직경/운동과 기존 수막 재고는 변경하지 않는다.

## 이번에 해결한 문제

이전 capsule은 각 선분을 개별적으로 정규화하면서 끝부분을 더한다. 같은 물량을
같은 직선에 놓아도 선분 개수에 따라 높이와 굴절 형상이 달라진다.
이 현상은 실제 제품의 모든 울퉁불퉁함을 설명한다는 주장이 아니라, 앞 단계
표시 후보에 존재한 구체적인 결함이다. 실제 제품 raster는 CPU 근사와 동일하지 않다.

새 `rainTrailLine.hlsl`은 정규화된 커널을 **선분 길이에 걸쳐 적분**한다.
정지에 가까운 구간은 작은 두 값의 차감 대신2점 적분을 사용한다.
폭과 단위 길이당 물량이 일정한 동일 직선에서는 선분을 나누어도 같은 결과가 된다.
무조건 `max`로 겹침을 지워 물량을 잃거나 물리적 물방울 크기를 키우지 않는다.

## 모델과 비용 선택

Gaussian 선적분의 error function을 추가하는 대신 compact quartic을 사용했다.
정의는 `K(x)=15/16*(1-x²)²` (`|x|<1`, 밖은0), 원시함수는 구간 내
`F(x)=1/2+15/16*(x-2x³/3+x⁵/5)`다. 두 축의 적분은1이다.
이 정의에서 직접 유도한 표시 커널이며 실측 바이저 수막 법칙이 아니다.
기존 Gaussian과 횡방향 분산을 맞추기 위해 support scale은√7/2배로 한다.
커널 모양 자체도 달라지므로 실제 이미지 차이를 모두 중복 제거 효과라고 하지 않는다.

가로 길이L인 선분의 밀도는 `V*K(v)*(F(u)-F(u-L))/L`이며 축/면적 변환을
추가한다. 연속 평면에서 적분 물량은V다. 이산 atlas 샘플, 경계 clipping과
표시 필터 뒤까지 정확한 동일 물량임을 뜻하지 않는다. 표시 결과를 물리 원장에
되먹임하지 않는다. 곡선 방향, 폭, 전달량/길이 변화는 여전히 모양을 바꾼다.

셰이더 자체는 다항식과 길이 계산을 쓰며 exp/erf, 텍스처 fetch, 가변 반복문이 없다.
그러나 실제 draw/이력 저장 비용은 별개다. 모든 화면 픽셀에서 모든 방울을 도는
구현이나 전체 물리 격자 확대를 채택하지 않는다. 기존 coarse 물과 detail을
중복 표현하지 않는 유한 이력 연결이 다음 제품 작업이다.

검토한 Gaussian 적분의 공식 정의: [NIST DLMF §7.2](https://dlmf.nist.gov/7.2).
최종 커널은 위 다항식을 직접 적분하며, 그 문서가 바이저 모델을 제안한 것은 아니다.

## 검증 결과

- 실제 전달 선분을 포함200개 입력을 CPU와 native HLSL로 비교했다.
- 같은 직선의1/4/16/64분할을 GPU10,625샘플로 별도 확인했다.
  최대 차이는 피크 기준8.20e-7, 즉 약0.000082%다.
- 길이0부터1000까지의 연속 평면 적분은 시험 물량.3mm³를 유지했다.
- native 검증은 D3D11 **WARP**다. 실제 CSP, 하드웨어 GPU 성능이나 수명/소유권
  검증을 대신하지 않는다. 제품 합격 기준을 이 미세 오차로 새로 만들지 않는다.

`split_invariance.png`는 동일 직선을1개/4개로 표시한 비교다. 기존 capsule은
양끝과 연결 지점이 달라지며 새 선적분 결과는 겹친다.1개/64개도 같은 검사에 포함된다.

## 실제 경로 표시 비교

앞 단계의 실제 KN5/128방울 subset, 속도0 초기화, 고정 캡처 힘, 건조 field1초에서
기록한362/175개 전달 선분을 재사용했다. 새 motion/trace 실행은 하지 않았다.
같은 위치·물량·표시 gain.31748로 기존 capsule/새 line과 단일/4점 field 샘플을
교차 비교했다. 수막 공급, impact, merge, 장기간 누적은 이 장면에 없다.

현재 coat 조건에서 최대 표시 높이는 기존 단일 샘플18.69µm에서 새 line12.49µm,
4점 field 필터에서는17.07→12.00µm다. 전달량은.514899mm³로 같다.
새 line+4점 필터의 이산 표시 적분은.514894mm³다. 이 차이는 표시 적분 결과이며
재고 손실/추가로 원장에 쓰지 않는다. 다른 재질 가설도 동일 입력으로 비교했다.

**실제 경로의 모든 불규칙함은 해결되지 않았다.** 방향/폭/전달량 변화, 원래 경로와
미세 굴절 샘플링이 남아 있다. 직선 분할 검사를 실제 곡선의 최종 품질 합격으로
확대하지 않는다. 같은 ROI/배율의 합성 배경이며 실제 게임 카메라가 아니다.

별도로 최종 RGB를2×2 샘플링 후 축소한 비교도 두 방식에 공통 적용했다.
이 경우 화면 경계의 거친 픽셀은 줄어든다. 높이/기울기를 미리4점 평균하는 것과
굴절 후 최종 색상을 평균하는 것은 같지 않다. 전자는 굴절의 비선형 샘플링을
적분하지 않기 때문이다. 추가 RGB 샘플링은 광학 참조 비용을 대략4배로 하므로
게임 전체 화면의 기본 설정으로 적용하지 않았다. 기존 게임 AA와의 중복도 미평가다.
