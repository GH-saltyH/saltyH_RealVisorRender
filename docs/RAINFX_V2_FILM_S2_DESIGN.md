# RainFX v2 — 막(sheet) 재설계 S2 (2026-11-13)
사용자 결정:
- 이전 sheet 기능(rev48-W1 / P2 / P4)을 모두 제거하고, 통합 모델(`RAINFX_V2_FILM_UNIFY_RESEARCH.md`, `_PLAN.md`)에 맞춰 새로 만든다.
- 사용자 관찰(sheet 켬): 주행 중 저품질의 큰 구역이 주변을 지우며 팝업했다가 곧바로 사라지기를 반복한다. sheet로 판정된 것 같은데 두께는 그려지지 않는다.

## 1. 관찰 원인 (이전 구조)
- **팝업:**
  - 핵생성(nuc.hlsl: 5×5 셀 방울 덮임 ≥ 0.5 + 젖음 + 충돌) 한 사건이 셀 무리의 방울들을 한꺼번에 막으로 흡수한다(merge의 r2SheetAbsorbFrac).
  - 방울이 동시에 지워지고(주변을 '지우며'), 같은 프레임에 넓은 h 패치가 생긴다.
- **곧 사라짐:**
  - 그 패치는 연결 판정(sheetConnA)이 끊기면 W1e / W1o 규칙(thinRate 지수 소멸, 질량 손실)이나 patch→bead(6 /s)로 사라진다.
  - 흐름은 Courant 0.24(≤ 0.068 m/s)라 움직이지 못한다.
- **저품질 / 어둠:**
  - 막 렌즈는 사전 업스케일 장면 복사본을 0.59 mm 텍셀의 h 기울기로 굴절시킨다.
  - 사건으로 생긴 계단형 h(블록 경계)가 큰 기울기 → TIR / 어두운 환경으로 읽혀 큰 검은 블록이 된다. P2e(평평하면 안 그림)와 섞여 두께감 없이 경계만 나온다.
- 결론: 생성(사건 흡수), 수명(연결 판정 / 상수 소멸), 수송(속도 상한), 그리기(블록 h의 기울기)가 모두 통합 모델과 다르다 → 재작성이 맞다.

- **cells:**
  - onSheet 탄생 억제(fed / connected).
  - W1m 잔류 위치(r2CellFilmCentroid).
  - BM bead 탄생.
  - fed 영역 lamella의 해상 몫 → 막.
- **merge:** r2SheetAbsorbFrac(연결 / 젖음 / hcAbs / rMax 조건 흡수).
- **field:**
  - W1j–W1w lamella 스탬프(충돌 → 막 타원, 거친 테두리).
  - fed 공급 q(F.a 평균).

  - thin film 규칙(thinRate 소멸, keep / lump, 연결 판정).
  - bead / nuc 제거 반영.
- **lam:** fed 플래그(+0.25)만 제거. 충돌 레지스트리는 cells의 탄생 사건이라 유지.
- **common:** r2SheetConnected / NucAt / HFed / ImpactFilm / FedTx / WetTx(공급 기반 젖음) / SheetAbsorbFrac / SheetH*. r2WetU는 깊이 기반 젖음만 남긴다.
- **visor:**
  - P2–P2e 막 렌즈(B-spline 등고선 + 메니스커스 + 융기 + q 평균 등고 수준).
  - P4 파도 / 충돌 크레이터.
  - Debug 10.
- **값 / UI:** sheet* 32개 → S2에서 필요한 것만 새 이름(film*)으로.
- **유지:** sheetcoef(공기 전단 + 중력 막 속도 계수, 윤활 법칙) → filmcoef. field B 채널 = 막 h. S1(물층 위 haze 흡수, 깊이 기반). TR0–TR2b trail.

## 3. S2 모델
1. **막 h의 원천(질량 보존, 사건 흡수 없음):**
   - 캡 과충만: 지금 cells는 최대 캡(maxRadius 3 mm) 초과분을 버린다('runs off', 질량 손실) → 그 초과분을 그 자리의 h로 보낸다. 큰 방울이 넘치면 물길이 된다.
   - 접촉 합류: 방울 발자국 아래 h ≥ h_c(물이 닿음)면 그 방울은 h에 합쳐진다(cells / field 같은 해시 판정, 단순 1개 규칙).
   - 충돌: 막 위(h ≥ h_c)에 떨어진 빗방울 / 분무는 h에 더한다(S1 공급과 같음). 마른 면 충돌은 지금처럼 cells(잔류 방울) / haze.
   - crown 유출(정지): 기존 그대로 h.
2. **수송 — 두 선택지 (§4 비용):**
   - **S2-Ta 질량 보존 유량(Courant ≤ 1, 상한 없음):** substep 수를 그 프레임 최대 막 속도로 정한다. 정지 / 저속에서는 1–3. 고속에서 막이 오래 살아 있는 경우(공급)만 비싸다.
   - **S2-Tb 고속 막 → 캡:** 길이 ≥ L_c이고 공급이 r2FedRate 미만인 막은 수명 W / 2V_d(θr 40°: 17–130 ms) 안에 끊어진다. 끊어진 물을 하류로 달리는 캡(셀 방울)으로 넘기면 고속 배수는 방울 시스템이 정확한 속도로 맡는다. 막 수송은 저속 Courant ≤ 1로 충분하다.
   - 권장: Ta(Courant ≤ 1, substep 상한 4) + Tb. 상한에 걸리는 빠른 막은 Tb로 캡이 된다.
3. **이동 판정:** Furmidge 길이 L_c = γ · pinCoat / (τ + ρ g_t h)(방울 depin과 같은 Δcos 0.18). 연결 덩어리 길이는 h > h_c 텍셀의 흐름 방향 연속 길이(셀 해상도 프리패스 1회) → 짧은 패치는 고정, 긴 막은 흐른다.
4. **가장자리 후퇴(F3):**
   - 공급 < r2FedRate인 막의 가장자리 텍셀은 V_d dt만큼 안쪽 테두리로 물을 옮긴다(질량 보존).
   - 흐르는 막은 옆으로 좁아져 물줄기가 된다. 테두리가 캡 크기에 이르면 셀 방울(캡)로 태어난다(cells / field 같은 해시, 1 셀 1 방울).
   - 상수 소멸 / 영구 잔류 없음.
5. **배수:** 바이저 밖으로 나간 물은 사라진다. 옆 수렴(두꺼운 쪽으로 끌림)은 유량에 포함한다.
6. **그리기(새 렌즈):**
   - h를 bicubic으로 부드럽게 보간하고, 등고선 h_c에서 가장자리를 θr 메니스커스로 둔다(서브텍셀).
   - 안쪽 기울기는 실제 막 기울기(작음) → 굴절 변위가 작다. **전체 해상도 장면**(사전 업스케일 복사본 아님)을 쓰고, TIR / 어둠은 가장자리 메니스커스에서만 둔다.
   - 블록 생성이 없으므로(사건 흡수 제거) 계단 기울기도 없다.

## 7. S2-1 + S2-2 구현 기록 (2026-11-13)
- **원천(field, merge):**
  - r2FilmJoin: 비행 / 소멸 중이 아닌 방울이 발자국(중심 + 4 테두리 점) 아래 막 ≥ gR2FilmWetMM(0.02 mm = haze의 물층 깊이)에 닿거나, 최대 캡(maxRadius)에 이르면 막이 된다.
  - field가 캡 윤곽 원판(≤ 1.9 셀)으로 깔고, 다음 프레임 merge가 같은 판정(같은 S, txR2FieldOld = 그 F_prev)으로 방울을 지운다.
  - 막 위의 미해상 비(filmRate)와 S1 haze 공급(B + R ≥ 0.02)을 막에 더한다.
  - crown 유출 유지. 상수 소멸(sheetDrain)은 S2에서 끈다.
  - 막(≥ 0.02)은 방울이 '수거'하지 않는다(합류 대상). 얇은 물만 수거된다.
- **가장자리 후퇴(r2FilmShed, field 모음):**
  - 막 텍셀이 마른 이웃을 가지면(가장자리) 공급이 r2FedRate(W 5 mm)보다 적을 때 V_d dt / dx(≤ 1) 몫을 가장 두꺼운 이웃으로 옮긴다. 국소 최고점(테두리)은 머문다 → 몸체가 여러 최고점으로 모여 구슬이 된다.
  - 막 옆의 얇은 물은 그 막으로 합류한다. 자기와 4 이웃의 판정을 모으므로 정확히 보존된다.
- **캡(r2FilmCapCell, cells + field):**
  - 셀의 최대 막 ≥ 0.02이고 둘레 8 셀에 막이 없으면 그 셀의 막 전체가 무게중심에 캡(셀 방울) 하나로 태어난다(cells, 프레임 1회, F_prev). field는 같은 판정으로 셀의 막을 비운다(이웃에서 들어온 몫만 남김).
  - 무작위 dewet 사건(sheet 끔 때만 유지)을 대체한다.
- **수송(film.hlsl, 새 패스):**
  - 업윈드 유량, 텍셀의 4 유출 합 ≤ 물(Courant ≤ 1 / substep).
  - substep: 0.3 mm 막 속도 기준, 짝수 2–4(4 → 0.14 m/s). 더 빠른 막은 고속에서 공급이 없어 몇 프레임 안에 캡이 된다 → 방울 속도로 배수.
  - 이동 판정: 막(≥ 0.02)이면서 흐름 축 연속 길이 ≥ L_c = 72 · pinCoat / (τ + ρ g 0.5 h) mm(≤ 8 텍셀 탐색). 바이저 밖으로 나간 물은 배수.
  - 계수는 sheetcoef(공기 전단 + 중력) 그대로.
- **값:** gR2FilmWetMM(= hazeWetMM), gR2FilmRefWMM 5, gR2FilmTauPa(½ ρ Cf u_e²), filmSub(Lua).
- **비용 절약:** 마른 이웃(자기 + 4 이웃 B = 0, 합류 / trail 물 없음)은 막 계산을 건너뛴다. 막 높이 Load는 마스크 표본 없이 한다(바이저 밖 텍셀은 항상 0).
- **그리기:** S2-3 전까지는 rev11 막 오버레이(gR2FilmMinMM = sheetHJoin 0.1부터 보임).

## 8. 게임 테스트 1 평가 (2026-11-13)

- 관찰:
  - Heavy rain 정차 중 큰 방울이 흐를 때 다른 굴절의 원형·파도머리 모양 군집이 생긴다. 녹색 광원 상이 면 전체에 맺힌다(평평한 면).
  - 이 덩어리는 흐르지 않고 제자리에 붙는다. 얇은 막은 보이지 않는다.

  - film 0.298 → 0.265 ms. 거의 줄지 않았다. 게이트는 여전히 open(1/256 F, M 없음)이다.
  - FXC 경고 X3556(블록 인덱스 int 나눗셈)이 있었다. uint로 고쳤다.
  - Debug 5는 접힌 경계의 밝은 회색(< 0.02 mm)만 보이고 색 변화가 없다.
- **F4d:**
  - film 수송은 MOBILE 몸체만 옮긴다(F5). 멈춘 막은 field의 규칙(후퇴, 캡, 공급)이 맡는다.
  - 그래서 게이트와 F4c 블록 판정을 mobile(G)로만 한다. 멈춘 막 한 점이 수송 전체를 붙잡지 않게 한다.
  - 지도는 그대로 F / M / B를 보여 주지만 'film blocks' 수는 F 또는 M 블록 수이고, 게이트는 M만 본다.
  - 새로 mobile이 된 몸체는 요약이 도착할 때까지(1–3 프레임) 기다렸다가 움직인다. 튀는 일은 없다.
  - F4c 결과에서 film 비용은 막 면적보다 서브스텝당 고정 비용(전체 field 쓰기와 패스 전환)이 크다. 게이트가 닫히는 것이 실제 절감 수단이다.
