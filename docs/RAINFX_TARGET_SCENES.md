# RainFX 환경별 시각 목표 — 사용자 영상 기준

재질 반응의 보정 축과 offline 가설은 [바이저 재질 모델](RAINFX_VISOR_MATERIAL_MODEL.md)을
따른다. 같은 물량·환경에서 접촉 형상, 이력, 잔류, 광학을 구분하며, 영상으로 목표
바이저의 물성을 실측했다고 간주하지 않는다. 현재 runtime 재질값을 변경한 것은 아니다.

2026-10-25. 사용자가 제공한 세 영상을 최종 장면 목표로 채택한다.
새로운 독립 probe나 세 개의 날씨별 하드코딩 preset을 만드는 과제가 아니다.
이번 작업은 영상 관찰·모델 연결·채택 기준 정의이며 런타임 변경은 없다.

후속 구현: [field 마름/micro 전환](RAINFX_PRODUCT_FIELD_LIFECYCLE.md)이 통합 경로에
연결됐다. 아래 '우선 복구' 요구의 코드 구현이며, 세 장면의 실제 품질 통과는 아직 아니다.

## 1. 자료와 관찰 범위

원본 폴더: `E:/_db_Media/Rec_Encoded/OBS_SOURCES_QHD/`.

|ID|파일명에서 사용자가 명시한 목표|길이|
|---|---|---:|
|A|고속주행다량의물보라_높은표면젖음과다수의빗방울충돌과강한굴절|22.567s|
|B|고속주행중중간비_haze및건조하게닦임|37.084s|
|C|약한비_대부분건조하게달라붙고이동됨_수막거의없음|39.167s|

Windows Media Foundation으로 각 영상16개 시점을 추출해 총48개 표본의 contact sheet를
검토하고, 각7.600/12.500/13.200s의 원해상도 표본도 확인했다. 모든 프레임의 연속
운동을 검증한 것은 아니다. 실제 시각은 contact sheet에 표시돼 있다.
메타데이터·SHA·표본: `diagnostics/2026-10-25/target_scenes/`.

직접 관찰: A는 조종석/중앙 구조물의 큰 불규칙 왜곡과 방울, 흐려진 원경이 함께
있다. B는 작은 방울·사선의 가는 흔적·부분적인 흐림과 선명한 영역이 공존하며,
표본마다 그 비중이 다르다. C는 대체로 선명하고 넓은 수막의 비중이 낮다.

파일명의 강우/물보라 조건은 **사용자가 지정한 목표 설명**이다. 영상만으로 mm/h,
RH, 표면 두께, 물성, 정확한 충돌 횟수나 마름 원인을 측정했다고 하지 않는다.
카메라 표면과 재질·거리·노출·초점, 바이저의 차이도 있으므로 원본 전체 blur나 색조를
우리 표면 효과로 복사하지 않는다. A의 공중 물보라/대기 흐림과 표면 굴절은 별개다.

## 2. 세 장면에서 만들어야 할 조합

|목표|유지해야 할 화면 특징|피해야 할 오판/결함|
|---|---|---|
|C: 낮은 공급·대체로 건조|불연속적인 작은 방울, 일부 고착/이동, 맑은 배경, 대부분 약하거나 없는 film|약한 비인데 시간이 지나면 micro가 전체를 채우는 현상; 모든 이동에 두꺼운 trail|
|B: 중간 공급·고속|가는 물길과 작은 방울, 국소 haze, 선명해지는 경로/구역, 제한적인 굴절|속도가 높다는 이유만으로 A의 전면 sheet; 균일 blur; 깨끗해진 자리가 즉시 절차 패턴으로 복구|
|A: 큰 실제 유입·높은 표면 물 재고|방울과 국소 충돌/퍼짐, 연결·변형되는 물, 강한 국소 굴절, 시야의 시간 변화|불변의 거대한 렌즈 패치; 모든 방울만 일괄 확대; 물보라 전체를 바이저 haze로 덮기|

같은 실제 환경에서 여러 상태가 위치별로 동시에 나타나야 한다. 세 상태를 전역
토글로 선택하지 않는다. 중간비의 고속 주행이 언제나 큰 film을 뜻하지 않으며,
맑아 보이는 표면도 물이 완전히0이라는 뜻은 아니다. 미세 물이 합쳐져 산란이 줄거나
얇고 평평해져 기울기가 작아지는 경우도 '건조하게 보이는' 결과를 만들 수 있다.

## 3. 모델이 구분해야 할 판단 축

|판단 축|사용할 입력/상태|표현에 연결|
|---|---|---|
|실제 액체 공급|현재 강수·DSD 추정, 표면 법선 입사 속도, 노출, 필요 시 명시된 스프레이 추정|birth/충돌 빈도와 공급 체적. rainIntensity만으로 모든 크기·효과를 증가시키지 않음|
|표면에 남은 물|위치별 head/film/micro 재고와 최근 유입/유출|얇은 길/연결된 물/고임의 발생과 유지. track wetness를 직접 복사하지 않음|
|충돌 상태|입사 속도·각도·크기·기존 젖음·코팅|붙는 물, 직접 film, 미세 물, 반발의 비율과 퍼짐|
|표면 운동|접선 상대풍·중력·관성·물리 크기·접촉 저항|고착/미끄러짐, 가는 경로/넓은 경로, 공급 대비 배출|
|미세 물의 체류와 해소|micro 공급·합류·명시된 제거/증발·이동 경로와의 상호작용|국소 haze와 선명한 길. 고습 환경의 빠른 시야 회복을 전부 증발로 설명하지 않음|
|광학 형상|head 접촉 형상, film 두께·gradient, 미해상 물의 분포|서로 연결된 표시 크기와 굴절. wetness와 opacity를 같은 값으로 취급하지 않음|

rainWetness/rainWater는 트랙 상태이며 바이저 수막의 강제 하한이 아니다. 물보라의
실제 센서 신호가 없으면 `rainWater×속도`만으로 A를 강제하지 않는다. 스프레이는
신뢰도와 상한이 있는 공급 추정으로 다루며, 지원되는 차량/노출 정보의 범위에서만
사용한다. 공급 추정 오차와 표면 운동 오차를 분리해 튜닝할 수 있어야 한다.

## 4. 현재 모델로 가능한 것과 필요한 연결

- **재사용:** SI 부피·접촉 크기·pinning/항력·관성 모델, DSD/가상 충돌 분배,
  같은 head 구간의 deposit, film 높이/gradient 광학. 세 목표의 기반으로 유지한다.
- **우선 복구:** 현재 s282에 빠진 field 마름과 micro→film 전환. 이것 없이 C의
  낮은 지속 coverage와 B의 시야 회복을 평가하면 누적 문제가 모델 선택을 왜곡한다.
- **필수 표시 계약:** head-only 축소와 coarse film footprint의 불균형,32Hz 위치
  유지 표시를 해결한다. 물리 수치를 바꾸지 않고도 시간/배율/필터를 명시해야 한다.
- **B의 추가 요구:** 기존 micro 재고의 양만큼 화면 전체를 흐리는 현재 방식으로는
  가는 선명한 경로를 보장하지 못한다. 같은 이동 구간과 연결된 micro 해소/재배분을
  최소 방식으로 구현해야 한다. 시각 마스크만 지워 물 재고와 무관하게 복구시키지 않는다.
  먼저 합류·배수·경로 표현의 저비용 조합으로 평가하고, 일반적인 고비용 흡수 solver를
  선행 조건으로 만들지 않는다. 보이는 haze가 자동 내부 결로라는 가정도 하지 않는다.
- **A의 추가 요구:** 충분한 공급에서 국소 물이 겹치고 퍼지는 표현은 필요하지만,
  모든 작은 head를 거대한 film과 일대일 대응시키지 않는다. 별도의 충돌 비산 animation은
  실제 부족함이 보일 때 제한적으로 추가한다. 현 공급 분배만으로 완성됐다고 하지 않는다.

고정된 haze/Smear/local impact film을 다시 켜서 세 영상을 흉내 내는 것으로 통과시키지
않는다. 같은 물 재고에서 나온 저비용 광학 근사는 가능하며, 추가 표현은 비용과 역할을
명확히 하고 물의 양을 별도로 만들지 않는다.

## 5. 실제 장면의 채택 순서

1. **C부터:** 실제 입력·낮은 공급에서 맑은 배경과 자연스러운 작은 방울/이동을 만든다.
   효과가 거의 없는 것이 올바른 결과인 구역도 합격으로 인정한다.
2. **B:** 공급을 늘리고 속도/전단을 바꿔 haze와 선명한 경로, 작은 방울/가는 물길이
   공존하는지 본다. C와 같은 물리/표시 계수를 쓰며 중간비 전용 숨은 보정은 금지한다.
3. **A:** 공급·기존 물 재고가 높은 상태에서 실제로 강한 굴절과 물의 연결이 생기는지
   본다. 비/스프레이가 줄면 다시 B/C 방향으로 회복되어야 한다.

각 단계는 별도 진단 앱이 아니라 **같은 통합 RainFX 경로**의 환경 변화다. 기존
대표 리플레이/실제 입력을 재사용하며, 새로운 조건별 로그 행렬을 매 수정마다 요청하지
않는다. 모션의 연속성·head/물길 크기·국소 선명도·굴절·회복과 전체 frame ms를 함께
판단한다. 원본의 세부 픽셀과 비트 일치, 관측하지 않은 실제 mm 수치의 재현을 요구하지 않는다.

이번 기준 채택으로 새 효과/수송 연구를 먼저 추가하지 않는다. 최소 경로의 구현은
C/B를 가능하게 하는 누락 복구와 시각 계약부터 하고, A에서 더 필요한 물 흐름의
복잡도만 채택한다. 현재 물리 모델의 잠재력을 실제 장면으로 확인하는 것이 목표다.
