# 바이저 재질 모델: 근거·보정 축·Python 평가 자산

2026-10-25. 상태: **자료 대조와 offline 모델 자산 구현. 게임 기본값 변경 전.**
목표는 레퍼런스 C/B/A의 재질 반응을 같은 물리 상태에서 구현하는 것이다.
차량 유리에 쓰인 CSP 효과를 그대로 축소하거나, '폴리카보네이트이므로 특정 수치'로
단정하는 방식은 쓰지 않는다. 기존 SI 질량·표현 배율 분리 원칙을 유지한다.

## 2. 차량 유리와 바이저 차이를 어디에 반영할 것인가

재질 차이의 입력은 기판 이름 하나가 아니라 **외부 코팅/오염·표면 형상·노출·내부 층**이다.
코팅된 차량 유리와 바이저가 같은 젖음 반응을 보일 수도 있고, 같은 PC가 서로 다른
코팅으로 다른 반응을 보일 수도 있다. 외부와 내부 면을 같은 profile로 묶지 않는다.

|독립 축|물리/표현 역할|현재 대응과 필요한 연결|
|---|---|---|
|평형 형상 θ|같은 V의 접촉 폭·높이·공기 노출|현재 공통 CONTACT_ANGLE90°. material별 형상으로 확장 필요|
|전진/후퇴 각 θA/θR|고착 임계·재고착과 방향 반응|현재 static span bare20°/coat4°. 형상과 독립 지정|
|동적 이력·점성 저항|움직이는 동안의 속도/멈춤|현재 dynamic span6°/2°,viscous shape80. 이 둘을 정지 임계와 따로 교정|
|충돌 젖음·반발·잔류|impact의 head/film/micro/bounce 분배|입사 We·각도·현재 visor wet 상태·material을 함께 사용. track wetness 대입 금지|
|잔류 트레일|이동 head에서 실제 film으로 전달할 양|현재 β bare.35/coat.05. 이 경험 계수를 접촉각만으로 자동 결정하지 않음|
|미해상 물의 분포|micro 광학 coverage와 국소 흐림|동일 물량도 대표 크기·접촉 형상에 따라 점유율이 다름. 단순한 equivalent µm와 구분|
|광학 경로|굴절·반사·정적 렌즈·샘플링|실제 camera-to-water 거리와 KN5 metric/곡률, 기존 E2/E3 층의 역할 유지|
|표현용 배율|해상도에서 읽히는 head/trail 크기|물량·접착·유입을 바꾸지 않으며 head만 독립 축소하지 않는 표시 계약 필요|

현재 한 coat 값이 '낮은 이력'과 '작은 β'를 동시에 선택하지만 두 성질이 항상 동반된다는
근거는 없다. 현재 coat가 바뀌어도 θ 자체는 공통인 점도 한계다. 모델 계약에서는
형상/정지 이력/동적 저항/잔류를 분리한다. 유효 코팅 mask 혼합은 경험적 유효 재질
근사로 표시하고, 혼합 방식을 실제 표면 법칙으로 단정하지 않는다.

공중 DSD는 같은 환경이면 유지한다. **같은 유입 V**가 다른 젖음성에서 다른 접촉
직경으로 보이는 것이며, 이를 공중 물방울 직경이나 질량에 되먹임하지 않는다.

## 3. 정량적으로 얼마를 보정할 수 있는가

`profiles.json`의 모든 새 profile은 **미측정 가설**이다. '바이저 표준값'이 아니다.
이미 게임에서 검증된 운동을 덮어쓰지 않고 독립 축을 비교하는 시작점이다.

예시: 공중 등가 지름3mm, V=14.137mm³, 형상 계수 k=1, 공기력 없는 중력 경사.
구면모자 형상과 Furmidge 형태의 저항을 쓰는 **현재 모델의 민감도**이며,
이 크기에서의 실제 중력 변형까지 푼 결과는 아니다.

|가설|θ|정지 이력 θA−θR|접촉 직경|중력 이동 시작 경사|
|---|---:|---:|---:|---:|
|현재 기본값|90°|20°|3.780mm|43.7°|
|퍼짐 비교군, 일반 차량 유리의 측정값 아님|65°|20°|4.635mm|50.1°|
|둥근 형상, 같은 이력|105°|20°|3.280mm|35.4°|
|둥근 형상, 낮은 고착|105°|8°|3.280mm|13.4°|
|둥근 형상, 높은 고착|105°|30°|3.280mm|59.6°|

같은 θ105°라도 낮은/높은 이력은 형상을 바꾸지 않고 운동 시작을 크게 바꾼다.
이를 '소수성' 한 슬라이더에 묶으면 영상에 맞는 고착·이동을 동시에 맞추기 어렵다.

θ90→105°에서 물리 접촉 폭은 약13.2% 작아지고 높이는 증가한다. 과거 표시 폭을
유지하는 **표현용 역보정**만 계산하면 gain.31748→.36589다. 실제로 적용하지 않았다.
head-only gain 변경으로 다시 trail과 어긋나지 않도록 공통 표시 계약이 먼저 필요하다.
이 역보정값을 물리 부피·힘·deposit 폭에 사용하지 않는다.

탐색 범위는 θ90–115°, static span4–30°, dynamic span2–12° 등으로 제한했다.
이 범위는 연구 자료의 보편적 물성 구간이 아니라 첫 후보의 **공학적 탐색 범위**다.
형상·이력·β·풍속 노출을 전부 동시에 fitting하지 않는다.

## 4. 트레일과 수막 보정

현재 식은 `h≈β*a*Ca^(2/3)`이고 유한 방울·기존 젖음에 대한 경험 근사다.
두 논문의 bath/impact 결과를 이 β의 실측 근거로 사용하지 않는다.
이동한다고 항상 연속 수막을 남긴다는 가정은 향후 재질/Ca/선행 젖음 gate에서
구분해야 한다. gate를 배경 opacity 삭제로 대신하지 않는다.

같은 현재 기본 형상과 속도0.05m/s에서 β.05/.15/.35는 각각 약0.74/2.21/5.16µm를
요청한다.10mm 경로의 head→film 전달량은 약.028/.084/.195mm³다.
순수한 β 변경만으로7배 차이가 나므로, 현.35/.05를 'PC 대 유리' 물성처럼 고정하지 않는다.
profile의 β는 의도적으로 null로 두고 독립 축 민감도만 생성했다.

이 값을 낮춰 이전 수송 후보의830mm 고임을 감추지 않는다. 얇은 film의 적용 범위를
넘는 고임은 같은 체적의 방울 전환/배출 모델로 분리하는 별도 필수 처리다.
모세관 길이/Bond 수는 이런 regime 판단의 보조 지표이며 범용 두께 hard cap은 아니다.

## 5. Haze·안개와 광학

미세 물의 같은 equivalent 높이20µm라도, 단일 등가 지름을.05→.1mm로 바꾸는
기하학적 coalescence proxy에서 θ90°의 접촉 면적 coverage는 약.614→.379다.
θ105°에서 같은 비교는 약.512→.301이다. 물의 양을 지우지 않아도 맑아질 가능성을
표현할 수 있음을 보이는 계산이다. Poisson footprint overlap 근사이며 산란/Mie
검증값이나 실제 micro 개수 관측은 아니다. 높이만으로 산란/coverage를 확정하지 않는다.

대표 크기·이동 경로와 결합한 수거/합류 처리가 없으면 material 광학 보정만으로
목표 B의 선명한 경로를 보장할 수 없다. 내부 결로는 표면 온도/이슬점과 흡습 층의
문제이며, RH가 높다는 이유만으로 외부 micro를 늘리거나 Pinlock 효과를 켜지 않는다.

물의 굴절률은 물의 특성이다. 바이저 기판/코팅은 접촉 형상, 정적 렌즈 층·반사·틴트,
그리고 기하학으로 반영한다. 현재 prism 근사의.333을 'PC 보정 계수'로 바꾸지 않는다.
같은 실제 field를50/100/200mm lever arm으로 렌더링한 sensitivity도 생성했다.
이 거리는 실측이 아니며 현재 게임 shader가 실제 pin.PosC 거리를 쓰는 것을 대체하지 않는다.
기존 E2/E3 정적 굴절/틴트를 수막 shader에서 중복 계산하지 않는다.

## 6. 게임 연결 순서와 비용 제한

1. 영상 C의 고착/이동과 footprint를 기준으로 θ와 static/dynamic 저항을 먼저 구분한다.
   영상만으로 수치가 유일하게 결정되지 않으므로 가설 confidence를 유지한다.
2. 같은 설정에서 B의 짧은 흔적·micro 해소를 비교한다. β·wet gate·micro optical proxy를
   별도 축으로 평가한다. 새 Smear나 강제 전면 film을 추가하지 않는다.
3. A의 큰 유입에서 bulk pool 분리·연결과 국소 굴절을 본다. 얇은 수막 범위 밖 체적을
   단일 거대 렌즈로 계속 렌더링하지 않는다.
4. 한 재질을 채택할 때 P1 접촉 폭/힘, P2 impact 응답, head→film descriptor,
   micro와 optics가 같은 material을 사용해야 한다. 재질 hash/reset 규칙을 유지한다.
   현재 offline setting mapping만으로 이 전체 연결이 완료됐다고 하지 않는다.

재질별 삼각함수·footprint/volume 계수는 CPU/LUT에서 미리 계산할 수 있다.
현 분기 구조에서 모든 pixel에 새 물리 모델을 실행하는 방식은 피한다. CSP의21tap이나
고정.002 이동 상수를 그대로 가져올 이유는 없으며 현재 해상도/시간/재질에 맞춰
단계별 수치 의미를 정의한다. 현재 작업은 새 GPU pass·게임 자원·tick 비용을 추가하지 않았다.

## 7. 자산과 검증

후속 [실제 메쉬의 짧은 운동 비교](RAINFX_MATERIAL_TRAJECTORY_REVIEW.md)에서는
bare20° 대조군과 실제 coat4° 영역을 구분했다.105°/8° 가설은 실제 현재 coat보다
이동이 적었다. low-pinning이라는 이름은 기준 상대값이며 자동 채택 근거가 아니다.

- `docs/reference/visor_material/sources.json`: 출처·읽은 범위·적용/비적용 판단.
- `profiles.json`: 독립 material 축과 제한된 가설 세트. 현재 default를 교체하지 않는다.
- `docs/tools/render_visor_material.py`: 실제 canonical SI HLSL 함수와 Python 계산 비교,
  동일 물량의 형상/고착 카드, β 민감도, micro coverage proxy와 setting mapping.
- `docs/tools/render_rain_product.py --material-distance`: 같은 물/광학 cap에서 거리만 비교.
- 결과: `docs/diagnostics/2026-10-25/visor_material/`의 PNG·review.json·delivery.json.

최종 검사:5개 재질×5개 크기의25조합을 D3D11 WARP1draw로 비교하고1program을 strict
compile했다. FP32 helper와 float64 계산의 최대 상대 차이는7.75ppm이다.
초기 oracle3ppm 기준은 이 함수의 근사 삼각함수 차이를 불필요하게 실패시켜10ppm으로
명시했다. 게임 물리 승인 기준을 바꾼 것이 아니며 material의 미측정 오차보다 훨씬 작다.
전체 실행2회에서 native draw2회, 최종 실행 통과. 거리 비교1회 통과.
이것은 실제 CSP·레퍼런스 장면 전체의 재질 적합성 검증이 아니다.
