## 1. 즉시 원인(관찰 2개)
- **팝아웃:** 잔류는 텍셀보다 작아(r ≈ 0.3–0.5 mm) 쌍선형 스플랫으로 field에 있었고, visor 윤곽(0.04 mm) 아래라 거의 보이지 않았다. age 23에 field가 회수하고 cells가 같은 부피 방울을 **완성 크기로**(나이 = growTime) 만든다. 보이지 않던 물이 한 프레임에 방울로 나타났다. 엔터티(방울)와 장(lamella)이 다른 렌더러라 연속일 수 없다.
- **사각 박스:** P4b 충돌 볼록은 visor가 ±2셀(≈ 2.3 mm) 창 안의 등록부만 읽는다. 그런데 볼록의 길이(최대 3.4 R0 ≈ 6 mm)와 하류 운반(250 mm/s × 0.2 s = 50 mm)이 창을 넘는다. 창 경계에서 잘려 셀 격자 사각형이 되었다. 짧은 τ와 큰 기울기가 반짝이를 만들었다.

## 3. 일관 파이프라인 제안: 충돌 사건 하나 → 결과 하나
### 3.1 원칙
1. **사건 단일화:** 프레임마다 충돌 등록부 하나(lam 패스 확장, 셀 해상도)가 모든 빗방울 충돌을 만든다. 위치, 지름 d(DSD), 법선 / 접선 속도, We / K는 같은 해시로 정한다. cells / field / visor는 이것만 읽는다(cells 자체 충돌 해시 폐지).
2. **결과는 착지면 + 충돌 물리로 한 번 결정**(질량은 충돌마다 닫힌다)
   - 마른 면 / 방울 없음 → **엔터티 lamella**(S2' splat 확장): 부착 몫(stick(K))이 퍼짐 f0(We) → 수축 → 잔류 방울이 되는 **한 방울 엔터티**다. 비산 몫은 위성 방울(해상 이상) + haze(이하).
   - 기존 방울 위 → 합류(방울 출렁임 표시) + 비산 몫이다.
   - 연결 막 / 습윤 / 피드 영역 위 → **장에 질량 추가** + 크레이터 / 교란(시각)이다.
3. **차원 분리 기준 = 크기와 연결성**(한 곳에서 결정)
   - 엔터티: 셀 창 안에 들어가는 구별 가능한 물(반경 ≲ 2 mm, lamella 포함). 형상 정밀도는 서브픽셀이다.
   - 장: 창보다 큰 연결 물(막, 습윤 층, 두꺼운 흐름, 트레일). 전이는 두 가지뿐이다: 엔터티 → 장(연결 막에 닿음 / 상한 초과 / 퍼콜레이션 핵생성), 장 → 엔터티(고립 패치 탈습 bead).
4. **단일 렌즈 높이:** visor에서 방울 커널 높이와 장 높이를 하나의 높이 H로 합성(매끄러운 합집합)하고, 굴절 / 테 / TIR을 한 번 계산한다. 엔터티가 장으로 흡수되면 질량이 같은 자리 같은 높이로 옮겨져 화면이 연속이다.
5. **충돌 시각화:** 엔터티 lamella는 방울 커널 자체(찢긴 테 = 윤곽 조화 + 손가락, 평평한 얇은 내부 + 두꺼운 테 프로파일)다. 장 위 충돌은 등록부 기반 해석 볼록으로, 창 경계 페이드와 운반 거리 상한(창 안)을 적용하거나, 장의 교란 채널에 침착해 장과 함께 이류(CSP 방식, 창 제약 없음)한다.

### 3.2 무엇이 사라지고 무엇이 남는가
- **사라짐:** field lamella 스탬프 / 수축(r2LamDep, lamHere), r2LamResidual(잔류 → 방울), cells 독립 충돌 해시, keep / lump 유지 규칙의 대부분, 마른 면 미해상 물 분해 경로.
- **남음:** 막 흐름(sheet), 습윤 층, 피드 판정(국소 q = 등록부에서), 연결성(nuc), bead(장 → 엔터티), S2' 퍼짐 / 수축(확장), 방울 물리 전체, P4 파도.
- **결과:** 규칙 수가 줄고, 모든 탄생에 원인 충돌이 있어 시각적으로 추적된다.

### 3.3 이득 / 위험 / 비용
- **이득**
  - lamella → 방울이 같은 엔터티의 형상 변화다(팝아웃 원천 제거).
  - 레퍼런스형 lamella(서브픽셀 테 / 손가락)다.
  - 충돌과 결과의 1:1 대응, 질량이 충돌마다 정확하다.
  - 규칙 단순화로 회귀 위험이 줄어든다.
- **위험**
  - (a) 엔터티 창 ±2셀 → 고속 대형 lamella(Rs > 2 mm)는 창 초과. 그러나 고속 노출 면은 피드 / 습윤(장) 영역이라 대부분 장으로 간다. 마른 면 고속 측면의 긴 lamella는 창 축소 상한(현행 S3b)을 따른다.
  - (b) 셀당 엔터티 1개 → 같은 셀 연속 충돌은 합류(물리적으로 맞음).
  - (c) 단일 높이 합성은 visor 렌즈 경로 재작성이다(가장 큰 작업).
- **비용:** field 스탬프 루프(25셀 × 3슬롯) 제거로 sim은 감소한다. cells 충돌 루프는 등록부 Load로 대체(비슷)한다. visor는 높이 합성으로 소폭 증가할 수 있다.

### 3.4 단계안
- **U1:** 충돌 등록부를 단일 소스로 하고 cells가 등록부를 소비한다. 마른 면 충돌은 S2' splat 엔터티(부착 몫 = 해상 + 미해상의 stick(K) 부분, 비산 몫 = 위성 + haze)다. field 마른 면 lamella는 제거한다.
- **U2:** splat 형상 확장. 테 프로파일(평평한 얇은 내부 + 두꺼운 테), Vt 방향 늘임 + 하류 손가락(윤곽 조화 고차), 수축 τ(θr) 공유.
- **U3:** 장 위 충돌 교란을 field 교란 채널에 침착하고 장과 함께 이류한다(사각 박스 제거, CSP식 끌림).
- **U4:** visor 단일 높이 합성(방울 + 장)이다.
- 각 단계 뒤 고정 환경 시뮬레이션(rainfx2_w1v_rest_sim.py 확장) + 인게임 확인.

## 4. U1 구현 (2026-10-31)
- **충돌 등록부 = 유일한 충돌 소스(lam.hlsl, 항상 실행, cells 앞)**
  - 셀마다 R = 이번 / 최근 충돌의 탄생 프레임 + 1(+0.25 피드), G = 이전 충돌(visor 교란용)이다. 율 = impactRate × 셀 면적 × 노출 × 군집(r2Cluster, cells에서 common으로 이동).
  - 해독은 common `r2ImpactAt`(위치, 지름 d, 해시)로 cells / field / visor가 같은 값을 쓴다.
- **cells(프레임당 1회, 서브스텝 1):** 5×5 등록부에서 이번 프레임 충돌을 읽는다.
  - 마른 면이면 **빗방울 자체**: 부착 몫 fRes = stickSlow (K0/K)^resA × πd³/6을 충돌점에 **방울 1개**(S2' splat f0 퍼짐 → 수축)로 만든다. lamella와 잔류가 한 엔터티다.
  - 비산 몫(1 − fRes)의 절반은 위성(크기 법칙, 테 / 하류 부채꼴), 나머지는 비산 / haze로 화면을 떠난다.
  - 기존 방울 위면 합류 + 밀림이다. 연결 막 / 피드 위면 cells는 아무것도 만들지 않는다(field).
- **field:** 피드 위 충돌은 물 전체(vU + vR, d³ 가중)를 lamella 타원(찢긴 부드러운 테)으로 막에 넣는다. 모든 충돌은 국소 공급 q에 기여한다. 연결 막(비피드) 위의 비는 기대값으로 합류(해상 + 미해상)한다.

### 4.1 U1 리뷰: 충돌 탄생과 미끄러짐 구분 (2026-10-31)
- FXC 17개 OK. 사용자: 충돌인지 흘러내림인지 혼동된다. 미끄러져 내려오는 중 살짝 팝하는 방울이 있다. 탄생 자체가 슬라이드인인가?
- **답(코드 기준)**
  - (1) 탄생 = 슬라이드인 성분이 있다(설계 S2 / S2'). 새 splat은 충돌 접선 운동량으로 초속 skid(min(shpSkidK × Vt/Vn × V/√(1 + (Vt/Vn)²), shpSkidMax = 0.05 m/s))를 받는다. 또 퍼진 발자국이 상류로 이동(lamShift)한 상태에서 하류 끝으로 수축한다. 정지 수직 바이저에서 비는 거의 접선(아래)이라 "위에서 미끄러져 들어오는" 모습이 된다.
  - (2) 미끄러지는 방울의 팝 = 그 방울에 충돌이 떨어져 합류한 것이다(부피 즉시 증가 + 밀림). 물리적으로 맞지만, 방울 위 충돌의 시각 단서(P4b 방울 렌즈 출렁임)가 약해 원인 없는 팝으로 보인다.
- **평가 도구:** "Highlight impacts"(자홍 = 충돌로 태어난 splat < 0.3 s, 노랑 = 이번 프레임 충돌이 떨어진 기존 방울). 슬라이더 "Impact skid"(shpSkidK, 0이면 슬라이드인 없음), "Splat footprint shifted upstream"(shpLamShift).

### 4.2 U1 결과 평가 (2026-10-31)
- **정지:** 별도의 splat 모습 없이 처음부터 방울 형태로 등장, 팝 → 수축 → 정지한다(sheet on / off 동일).
  - 원인: f0 = 1.8 + log 항(We_n), We_n은 법선 속도 V / √(1 + (Vt/Vn)²)로 정한다. 정지 수직 바이저에서 비는 거의 접선이라 Vn이 작고 f0 ≈ spreadMin(1.8)이다. 프로파일도 방울 돔(테 / 얇은 내부 없음)이다. 즉 "조금 큰 방울 → 수축"이다.

- 비용: sheet 273 km/h 1.26 / 1.19 ms, sheet 정지 1.47 / 1.09 ms(sim / draw).
- **U2 범위(사용자 관찰 반영)**
  1. splat 프로파일: 두꺼운 테 + 평평하고 얇은 내부(레퍼런스 f355–379), 퍼짐 f0는 전체 충돌 속도 기반(마른 면 사선 충돌도 lamella는 넓게 퍼지고 Vt 방향으로 늘어남), Vt 방향 늘임, 하류 손가락(윤곽 조화 고차 + 찢김), 수축 τ(θr).
  2. 탄생 직후 부착: splat 수명 동안(접촉선이 퍼지는 중) 공기 / 중력 구동을 0 → 1로 램프하고 skid를 없앤다. 수축 후 고정력 판정으로 넘긴다(공 튀김 제거).
  3. 탄생 위치: 충돌점 = 퍼짐 중심, 잔류는 하류 끝(현행 lamShift는 시각만, 질량 중심 이동은 수축 동안 점진).

## 5. U2 — splat lamella, 탄생 부착, 탄생 위치 (2026-11-03)
- **퍼짐 f0(cells):** We = ρ V_imp² d / γ로 바꿨다. V_imp는 전체 충돌 속도(노출 반영), d는 빗방울 자신의 지름이다. U1은 법선 속도와 잔류 크기를 써서 f0 ≈ spreadMin에 묶였다. 사선 벽에서도 β_max ∝ We^¼는 전체 속도를 따른다(Yeh 2013, Almohammadi 2017). 정지(약 7 m/s, d 2 mm, We ≈ 1360)에서 f0 ≈ 3.0–3.2가 된다.
- **lamella 프로파일(visor r2Kernel, SP 인자):**
  - 돔을 테 토러스 6.75 x²(1−x)(x = r²/R², r = 0.82 R에서 최대, 중심과 가장자리에서 0) 쪽으로 ρ만큼 섞는다. 기울기도 해석적으로 함께 섞는다.
  - ρ = shpRimK(0.6, 최대 0.85) × sat(f − fB)이다. 내부 두께는 (1 − ρ)이고 수축하면서 돔으로 돌아간다.
  - **하류 손가락:** 반경을 1 + fk·cos³₊(8ψ + 위상)·sat(0.25 + 0.75 cosψ_down)로 변조한다. fk = shpFingerK(0.25) × sat(f − fB) × (0.3 + 0.7 sat(Vt/Vn / 2))이다. 방향은 픽셀별 충돌 Vt 방향(air.iDir)이다.
- **수축 τ:** τ = shpSpreadTau × 50 / θr(sheetRecedeDeg)이다(cells / visor 공통). 후퇴각이 낮으면(때 / 마모) 테가 오래 붙잡혀 느리게 수축한다. 50°에서는 기존 값과 같다.
- **탄생 부착(r2Predict):**
  - splat(life.w < −9.5)의 공기 / 중력 구동(vt, speed, drive)에 smoothstep(0, 3τ, age)를 곱한다. 램프 동안에는 발사(shed)를 금지한다.
  - 새 splat의 skid를 없앴다. 맞은 기존 방울의 밀림만 남는다(shpSkidK).
- **탄생 위치:**
  - 방울은 충돌점에서 태어난다. 잔류는 수축 동안 하류(Vt 방향)로 δ·(1 − e^(−age/τ))만큼 결정적으로 걷는다. δ = shpLamShift × r × (f0 − 1) × min(1 + Vt/Vn, 2)이다.
  - 이 걸음은 관성 속도에서 뺀다(운동량 아님).
  - visor는 lamella 중심을 방울 − Vt·δ·e(1 − e)에 그린다. 탄생 시 충돌점이고 끝에서 방울이므로 점프가 없다. 기존의 고정 상류 이동 0.5 r fx/f는 대체했다.
- **새 파라미터:** shpRimK 0.6, shpFingerK 0.25(UI). 의미가 바뀐 것: shpLamShift(잔류 하류 걸음), shpSkidK(맞은 방울 밀림만).
- **값 전달:** sceneValues에 gR2ShpSpreadTau를, drawParams에 gR2ShpLamShift / RimK / FingerK를 추가했다.
- **확인 항목:**
  - 정지에서 splat이 넓고 얇은 테 원반으로 보이는지, 수축 후 방울이 되는지.
  - 주행에서 튀어 나가지 않고 붙어 수축한 뒤 출발하는지.
  - Highlight impacts로 탄생과 합류를 구분할 수 있는지.
  - 분포(p99/p50 ≥ 10)가 유지되는지.

### 5.1 U2 리뷰 → U2a (2026-11-04)
- **리뷰(맞바람 120 km/h, intensity 100 %, sheet off):**
  - 원반 splat이 보이지 않는다. 자기 모양이 확대됐다 축소된다(콩팥 / 땅콩형이 가장 어색하다).
  - 수축 중에 출발한다.
  - 튀는 현상은 없어졌지만 팝콘 같은 tick이 남았다. 합류 시 새 랜덤 모양과 회전이 생기고 시각 질량이 일관되지 않다.
- **원인(코드):**
  - S2'가 방울 자신의 윤곽 조화(a2, a3)를 (1 + 2 fx)배로 키워 splat을 그렸다. 그래서 lamella가 방울 모양의 확대판(콩팥)이 됐다.
  - 램프 smoothstep(0, 3τ)은 1.5τ에서 구동 50 %(아직 22 % 퍼진 상태)이다.
- **U2a 수정:**
  - **lamella 고유 형상:** Vt 방향 타원(종횡비 = r2ImpactGeom z = min(1 + shpImpactK·Vt/Vn, shpImpactMax))에 하류 손가락을 더한다. 수축하면서 방울의 정지 형상으로 바뀐다.
    - 두 발자국 이차형식을 e = exp(−age/τ)로 섞는다: Q = (1 − e) Q_drop + e Q_lam (Q = uuᵀ/A + vvᵀA). 고유분해로 단일 타원(축, 종횡비)을 얻으므로 축 뒤집힘이 없다.
    - 방울의 조화 / 굽힘 / 처짐은 (1 − e)로 들어온다. 조화 증폭은 제거했다.
  - **창 상한 / 도달 거리:** lamella 종횡비 상한을 e로 연속 반영한다(상한 전환 점프 없음).
  - **부착 램프:** smoothstep(2τ, 4τ)로 바꿨다. 수축 86 %까지 구동 0, 4τ까지 발사를 금지한다.
  - drawParams에 gR2ShpImpactK / Max를 추가했다.
- **한계:** visor는 방울을 ±2셀(약 2.3 mm) 창에서만 그린다. 이보다 큰 lamella는 전체가 축소되므로 큰 방울의 splat은 상대적으로 덜 퍼져 보인다(U4 단일 높이 합성에서 해소 후보).

## 6. 제안 M — 합류 형상 기억(merge footprint) (2026-11-04, 승인 대기)
- **문헌:**
  - Andrieu, Beysens, Nikolayev 2002(JFM 453, arXiv 1601.06961): 다리(bridge)는 20 ms 미만에 형성된다. 합체 방울은 먼저 길쭉한 볼록형이 되고, 이후 긴 축 R_y만 줄고 짧은 축 R_x는 거의 그대로 지수 이완한다(t_c = R*/u, 수 s). 질량 중심은 R³ 가중으로 큰 방울 쪽에 있다. 이완 속도는 접촉선(후퇴)이 정한다.
  - Hernández-Sánchez 2012(PRL 109, 184502): 위에서 본 다리는 경계면에서 빠르게 채워진다. 크기 / 각이 다르면 다리가 작은 각 쪽으로 이동한다.
  - 히스테리시스가 있으면 θ_comp가 θr 위에서 멈춰 길쭉한 채 남는다.
- **현행 결함(코드):**
  1. 발자국 면적이 r1² + r2²(합집합)에서 rm²로 즉시 줄어든다(같은 크기 쌍 −21 %). 시각 질량이 줄어 팝으로 보인다.
  2. 승자의 윤곽 조화는 새 장축 기준으로 그려진다. 합류로 장축이 돌면 윤곽도 같이 돌아 회전 팝이 생긴다.
  3. 크기가 다른 쌍도 대칭 타원 + 허리이다(큰 쪽이 큰 '달걀형'이 아님).
- **M1 발자국 면적 기억:**
  - 합류 직후 발자국 = 합집합 면적이다. 부피가 보존되므로 프로파일은 낮아진다.
  - 접촉선 후퇴 조건에서만 줄어든다. θ_comp ∝ V / A^{3/2}가 θr보다 작을 때 긴 축 방향으로 지수 이완한다(τ ∝ R, 후퇴각이 낮을수록 느리다). θr에 닿으면 멈춘다(길쭉하게 고정).
  - 상태: 발자국 초과율(현 fU, 프로파일 전용)을 발자국 반경에도 쓴다.
- **M2 방향 연속:** 비대칭 윤곽 조화(a3)의 위상을 장축이 아닌 세계(visor) 좌표 기준으로 바꾼다. 합류 / 회전에서 윤곽이 돌지 않는다.
- **M3 비대칭 쌍:** 장축 방향 1차 모드(달걀형, 큰 쪽으로)를 상태 비트(조화 팩 여유분)에 추가한다. 허리(다리)는 경계면에서 빠르게 채워지며 큰 쪽 / 작은 각 쪽으로 이동한다.
- **비용:** 셀 / 병합 패스 산술만 늘고, visor는 커널 1항이 추가된다.
