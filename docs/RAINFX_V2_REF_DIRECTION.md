# RainFX v2 레퍼런스 분석 & 디렉션 지침 (2026-11-04)

새 레퍼런스 4편(1080², 60 fps)을 분석했다. 프레임 시트는 `docs/diagnostics/2026-11-04/refs/`에 있다.

| ID | 영상 | 조건 |
|---|---|---|
| A | 약간 많은 비, 100 km/h 근처 중저속(61 s) | 포뮬러 헬멧캠. 방울 분포, 고임, 흐름 속도 |
| B | 중간 비, 퍼들 많음, 앞차 물보라(102 s) | F1 헬멧캠(Brazil 2024). 물보라 속 / 밖의 습윤 상태 |
| C | 2026-11-01 19-18-54(20 s) | F1 헬멧캠, 폭우. 막 / 줄무늬 흐름, 강한 색 광원 |
| D | 약한 비, 앞차 물보라, 60–250 km/h(26 s) | F1 헬멧캠(Imola). 속도에 따른 축적 / 정리, 물보라 진입 |

방법:
- 시트(영상 전체 12장), 확대, 연속 프레임(6–15 프레임 간격)을 육안으로 분석했다.
- 방울 크기의 자동 검출(blob)도 시도했지만 초점 흐림과 배경 대비 때문에 신뢰도가 낮아 수치는 참고만 한다. 1080 기준 방울 원반 p50 약 12–14 px.

## 1. 관찰 결과

### 1.1 광학: 방울은 '초점이 나간 원반(bokeh)'이다 (A, D, B)
- 헬멧캠과 운전자의 눈은 먼 트랙에 초점을 둔다. visor 방울(눈에서 3–5 cm)은 테가 또렷한 렌즈가 아니라 부드러운 원반이다.
  - 작은 방울은 모두 비슷한 크기의 원반이 된다(최소 원반 = 착란원). 그래서 크기 차이는 큰 방울에서만 읽힌다.
  - 원반 안에는 뒤집힌 밝은 배경이 흐리게 비친다.
- **보이는 정도는 배경이 정한다.**
  - 밝은 하늘 앞에서는 방울이 거의 안 보인다(옅은 회색 유령, 어두운 테 약간).
  - 어두운 실내(스티어링, 계기판) 앞에서는 밝은 점 / 테로 잘 보인다(하늘을 굴절해 비춤).
  - 그래서 위쪽(하늘)은 깨끗해 보이고 아래쪽(실내)은 방울로 가득해 보인다. 물의 분포 차이가 아니라 광학이다.
- **강한 색 광원**(앞차 후미등, LED, C의 파란 / 빨간 빛)이 있으면 모든 방울이 그 색의 하이라이트를 가진다(D, C). 방울을 인지하는 가장 강한 단서이다.

### 1.2 분포와 밀도 (A, D)
- 중저속(약 100 km/h) 꾸준한 비에서는 visor 전체가 이산 방울로 빽빽하다. 덮임 약 25–45 %(실내 앞에서 체감)이다.
- 크기 폭이 넓다. 미세 점(서브 mm)이 다수이고, 1–3 mm 방울이 흩어져 있으며, 위쪽 가장자리 / halo 그늘 쪽에 큰 불규칙 고임(3–5 mm, 합쳐진 덩어리)이 있다.
- 격자 / 균일 간격은 보이지 않고, 뭉침과 빈 곳이 섞여 있다.

### 1.3 움직임 (A, D)
- **약 100 km/h에서 방울은 거의 정지**한다. 1 s 동안 위치 변화가 거의 없다. 화면 변화의 대부분은 머리 움직임에 따른 배경 변화이다.
- **고속(200 km/h 이상) 직선**에서는 visor가 비교적 깨끗하다(D, 238 km/h). 큰 방울은 공기 방향(바깥 / 위)으로 밀려 나가고 미세 방울과 습윤 막만 남는다.
- **코너 / 감속**(3단, 2단)에서는 수 초 안에 다시 방울이 빽빽해진다(D). **축적은 수 초, 정리는 약 1–2 s**이다.
- 흐름은 공기 방향의 대각 / 수평 줄무늬(rivulet)로 보인다(C, B 아래). 중력 방향(아래)은 거의 없다.

### 1.4 물보라 (B, D)
- 앞차 물보라 속에서는 장면 전체가 흰 안개로 덮인다. 이것은 **대기(CSP 입자 / 안개 영역)**이다.
- 아주 가까우면 visor가 **연속 수막**이 된다(B 위). 상이 크게 일렁이고 번지며, 방울 경계가 없다.
- 물보라를 벗어나면 수막이 1 s 안팎에 수많은 작은 방울과 줄무늬로 갈라진다(B 아래).
- 물보라 없이 젖은 상태에서는 미세 방울 / 습윤으로 전체 대비가 약간 떨어진다.

### 1.5 폭우 + 속도 (C)
- 아래쪽 실내 앞에 날카로운 미세 점(하이라이트)이 빽빽하다. 그 위로 **공기 방향의 대각 줄무늬**가 지나가고, 전체에 얇은 막의 일렁임이 있다.

## 2. 디렉션 지침 (목표 이미지 기준)

### 2.1 상황별 목표

| 상황 | 목표 이미지 | 관찰 기준 |
|---|---|---|
| S1 중저속 ≤ 120 km/h, 물보라 없음 | 빽빽한 정지 방울장, 넓은 크기 폭, 위쪽 가장자리 고임 | 1 s 동안 방울 대부분 정지. 큰 방울(r > 약 2 mm)만 mm/s–cm/s로 미끄러짐 |
| S2 고속 ≥ 200 km/h 직선 | 부분적으로 정리된 visor, 미세 방울 / 습윤 잔류 | 큰 방울은 1–2 s 안에 공기 방향으로 빠지고 작은 방울은 남음 |
| S3 감속 / 코너 | 수 초 안에 재축적 | 정리보다 축적이 느림(비대칭) |
| S4 물보라 속(가까움) | 연속 수막(상 번짐 / 일렁임) + 대기 안개 | 방울 경계 사라짐. 안개는 visor가 아니라 대기 |
| S5 물보라 이탈 | 수막이 작은 방울 + 줄무늬로 분해 | 약 1 s, 팝 없이 연속 |
| S6 폭우 + 속도 | 미세 점 + 공기 방향 대각 rivulet + 얇은 막 | 줄무늬는 중력이 아니라 공기 방향 |

### 2.2 광학 지침
1. **초점 흐림을 기본으로 한다.** 방울은 착란원 원반으로 그린다(기존 D-A defocus, apertureMM > 0). 목표: 1080p에서 가장 작은 방울 원반 약 8–14 px, 테는 부드럽게.
2. **보이는 정도는 굴절된 배경이 정한다.** 하늘 앞 방울은 흐리게, 실내 앞은 밝은 점 / 테로 보이게 한다. 대비를 인위로 올리지 않는다.
3. **광원 하이라이트:** 장면의 밝은 / 색 광원이 각 방울 원반 안에 맺혀야 한다(scene 샘플이 bloom 이전의 밝은 값을 유지).
4. **안개는 visor가 아니다.** 물보라 안개는 CSP 대기 영역이다. visor는 수막 / 미세 방울로 대비만 떨어뜨린다(사용자 원칙: atmospheric veil 미변경).

### 2.3 물리 지침
1. 정지 우세: 중저속에서 방울은 고정된다(R6b shedU10 20과 일치).
2. 속도 비대칭: 고속 정리 약 1–2 s, 재축적 수 초. 고속에서 큰 방울은 빠지고 작은 방울은 남는다.
3. 흐름 방향은 공기가 지배한다. 줄무늬와 runback은 공기 방향이다(대각 / 바깥 / 위).
4. 고임: 위쪽 가장자리와 halo 그늘에 큰 불규칙 덩어리(crown runoff, 합류 M1).
5. 물보라 → 수막 → 분해: W1 sheet 경로(fed regime, dewet)와 같은 순서이다.

### 2.4 하지 말 것
- 공중으로 날아가는 streak(R6에서 삭제), 균일 격자, 모든 방울에 같은 테 두께.
- 하늘 앞 방울을 인위로 진하게 하기, visor에 흰 안개 덧칠하기.
- 1 프레임 팝(탄생 / 합류 / 분해 모두 연속).

## 3. 현재 구현과의 차이 → 작업 우선순위

| # | 항목 | 현재 | 조치 |
|---|---|---|---|
| D1 | 초점 흐림 | apertureMM 0(꺼짐) | defocus 켠 상태를 레퍼런스 기본으로 한다. A / D 프레임과 원반 크기를 맞춰 보정한다 |
| D2 | 고속 정리 속도 | 300 km/h 직선에서 r2만 0.11 m/s | S2 기준(큰 방울 1–2 s 정리)으로 shedU10 15–20을 재평가한다. 작은 방울 잔류는 유지 |
| D3 | 분포 / 고임 | p99/p50 약 7, 비슷한 크기 단조로움 | 분포 재검토(물 잔류 경로 분해 먼저). 가장자리 고임 확인 |
| D4 | 물보라 수막 | sheet 기본 off | S4 / S5 시나리오(앞차 물보라)에서 sheet on 검증. 수막 → 분해 연속성 |
| D5 | 공기 방향 rivulet | trail은 이동 방향을 따름 | 고속 / 폭우에서 줄무늬 방향과 길이를 C와 대조 |
| D6 | 광원 하이라이트 | 굴절 / 반사 기반 | 색 광원 장면(D, C)에서 방울 내 하이라이트 확인 |

권장 순서: D2(물리 확인) → 물 잔류 경로 분해 + D3 → D1(광학) → D4 / D5 → D6 → U4.
