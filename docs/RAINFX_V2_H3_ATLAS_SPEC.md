# RainFX v2 H3 미세 물방울 아틀라스 — 최종 사양 (검토용, 2026-11-12)

근거: `docs/RAINFX_V2_SPRAY_RAIN_REF.md` §26–29.11, 프로토타입 `docs/prototypes/rainfx2_microdrop_atlas_sim.py`, `rainfx2_overlap_cut_sim.py`, `rainfx2_overlap_size_grid.py`, `rainfx2_h3_cell_micro_proto.py`, 레퍼런스 `docs/reference_frames/microdrop_ref_window.png`.

## 0. 목적과 경계
- 셀 방울(r ≥ a_max ≈ 0.3 mm, 움직임 / 합체 / 흔적 시뮬레이션) **아래 크기의 물 전부**를 한 층으로 그린다.
  - 하얀 haze(분해되지 않는 고운 캡)
  - 미세 물방울 군집(분해되는 0.03–0.3 mm 캡, 서로 잘린 다양한 모양)
- 물량은 지금처럼 haze 층(HZ)이 갖고, 아틀라스는 **모양만** 준다(질량과 무관한 표시 금지 원칙 유지).
- 굽기는 오프라인 1회, 시뮬레이션 패스 추가 없음.

## 1. 데이터 흐름
```text
[오프라인] bake tool → microdrops.dds (타일, 법선 / 높이 / 순위 + 자체 mip)
[매 프레임] cells → hzm → haze : HZ = (G_f 고운 물, G_c 조대화된 물), 닦임 / halo / 공급 / 증발 / 핵생성
[visor]    HZ(G_f, G_c) + 화소 발자국 + 디포커스 CoC → 옥타브 / 순위 / 분해 판정 → CSP 셰이딩 + 하얀 산란
```

## 2. 아틀라스 굽기 (`docs/tools/rainfx2_bake_microdrops.py`, 신규)
### 2.1 배치 (물리)
- 주기 타일 위 breath figure: **성장 + 합체(부피 보존, 질량 중심) + 빈 곳 재핵생성**. 큰 방울 둘레의 고갈대와 틈의 작은 세대가 저절로 생긴다.
- 재핵생성을 여러 세대로 나눠 0.05–0.2 mm 중간 크기를 늘린다(§29.8 사진 대비 부족분).
- 목표: 덮임 ~0.6, 구운 크기의 보이는 r p50 ~0.3 mm(옥타브 0), 최대 ~0.45 mm.
- 미세 방울은 Bond 수가 작아 처짐 없음(셀 방울만 처짐).

### 2.2 모양 (겹침-잘라내기, 2026-11-12 개정 — CSP 출력 예시 `docs/reference_frames/csp_overlap_example.png`)
사용자 결정: 크기 법칙만으로 다양성을 내지 않는다. **여러 크기를 촘촘히 겹쳐 놓고, 겹친 경계를 확실히 깎아** 조각의 모양 / 크기가 다양해지게 한다. 방울 사이 구분감을 분명히 한다.
1. 배치: 주기 타일 위 포아송, 반경 pdf ∝ r^−2.2(0.03–0.5 mm), 그려진 면적 밀도 D = Σπr² / 타일 면적 > 1(거의 모든 방울이 여럿과 겹침).
2. 소유: 텍셀마다 점수 최대 방울. S_i = r_i²(1 + zmix·P_i) − d_i²(파워 거리, P_i ~ U(0, 1)).
   - zmix 0: 파워 다이어그램 → 두 원의 교점을 잇는 **직선 현**으로 나뉜다. 큰 원 깊숙이 든 작은 원은 사라진다(합쳐졌을 것) → 섬 없음, 작은 방울은 가장자리 / 틈에 남는다.
   - zmix > 0: 방울마다 무게 → 현이 약한 쪽으로 밀려 한쪽은 거의 온전, 다른 쪽은 조각(CSP의 청록 / 주황, 노랑 / 보라 쌍).
3. 틈: 방울마다 확률 gapP로, 다른 방울과의 절단선을 따라 gapMM(0.025 mm) 마른 띠를 둔다(한쪽 / 양쪽 틈이 섞임). minPieceTex(6 텍셀) 미만 조각 제거.
4. 조각 표면: 조각마다 **일정 곡률의 액체 캡** — 푸아송 ∇²h = −κ_i(내부), h = 0(조각 가장자리), κ_i = 2·rimSlope / R_eq. 원이면 포물면, 잘린 조각이면 윤곽을 따르는 돔(거리장 지붕의 면 분할 없음). 이어서 h ← H(h/H)^steep(0.7: 림은 가파르게, 위는 평평하게). 맞닿은 두 조각 사이의 경계 텍셀은 어느 쪽도 아니다(h = 0) → V자 홈 = **확실한 구분**.
5. 비교(`docs/prototypes/rainfx2_h3_overlap_variants.png`, 12.8 mm 굽기, 소유 지도 / 음영 2.5 mm / 게임 축척):

|---|---|---|---|---|---|---|
|A|1.5|0.5|50 %|0.70|0.050 / 0.193 / 0.50|~1560|
|B|2.2|0.5|50 %|0.78|0.052 / 0.227 / 0.49|~1510|

- 겹침 선택은 사용자 비교 후 결정(굽기 매개변수: density, zmix, gapP, gapMM).

### 2.3 채널 / 형식
|채널|내용|비고|
|---|---|---|
|R, G|법선 xy(부호, 높이 기울기 = 축척 불변)|옥타브 축척과 무관하게 그대로 쓴다(자기유사)|
|B|덮임 / 두께(0 = 빈 곳)|하얀 산란의 평균 덮임, 굴절 가중|
|A|순위(방울 id의 해시, 나타나는 순서)|덮임 임계용. 방울 안에서 상수|
- 해상도: 텍셀 12.5 µm. **1024²(12.8 mm 타일, 5.6 MB) 또는 2048²(25.6 mm, 22 MB)** → 결정 필요(반복 대 메모리).
- mip은 도구가 직접 만든다: 법선 평균(→ 평평), 덮임 평균, 순위 = 덮임 가중 대표값. 화소보다 작아지는 mip은 덮임 평균만 의미가 있다(하얀 산란 경로).
- 형식: RGBA8 무압축 권장(순위 / 법선 정밀도). BC7은 순위 경계가 섞일 위험 → 측정 후 선택.
- 도구 출력: DDS, 크기 히스토그램 / 덮임 / 옥타브별 보이는 크기 표, 미리보기 PNG.

## 3. 런타임 선택 (visor, H3-a)
### 3.1 입력
- HZ 이중 선형 표본 1회: G_f, G_c(이미 G를 읽는 자리, 추가 비용 거의 0).
- 화소 발자국 p_mm = 바이저 mm 좌표의 ddx / ddy.
- 디포커스 흐림 반경 c_mm = A·|z_f − z| / z_f(기존 `cocMM`, apertureMM 0이면 0).
- **R_res = max(p_mm / 2, c_mm)** = 한 점으로 구분되는 크기.

### 3.2 크기 / 덮임
- 포화 전(G_c < G_sat): a_eff = a_min(가장 고운 옥타브), 덮임 φ = 1 − exp(−π h / (shapeK a)) ≤ φ_max.
- 포화 후: 덮임 φ_max 유지, **a_eff = a_min · G_c / G_sat**(자기유사 조대화: 평균 크기 ∝ 물량), 상한 a_max.
- 옥타브 L = log2(a_eff / a_atlas). 이웃 두 옥타브를 소수부로 교차 혼합. 옥타브마다 고정 회전 / 오프셋(타일 반복 완화, 좌표 고정 → 미끄러짐 없음).
- 순위 임계: 방울이 보이는 조건 rank < φ / φ_max, 부드러운 폭 0.08(하나씩 서서히 나타남 / 사라짐, 1프레임 팝 없음).

### 3.3 분해 판정 (하얀 haze ↔ 군집)
- w_det = saturate(log2(a_eff / R_res) · k + 0.5): 방울이 구분되는 정도.
- 아틀라스 표본의 lod = log2(R_res / 텍셀 축척) → 고운 옥타브 / 큰 CoC에서는 mip이 자동으로 평평 + 덮임 평균 = 하얀 산란.
- 출력 = w_det × (군집 셰이딩) + (1 − w_det) × (덮임 평균의 하얀 산란, 기존 H1 식) — 한 경로라 경계가 없다.

### 3.4 셰이딩 (CSP 윈드스크린 식, 셀 방울과 같은 규칙)
- nz > 0.3: 화면 굴절(uv −(N·side, N·up) × k_micro; k_micro 시작값 0.12 화면, 장면 mip은 방울 크기 / 흐림에 맞춤).
- 가파른 림: 큐브맵(월드 방향) × 0.7.
- 반사 (1 − nz)³.
- 하얀 산란: 주변광(장면 산란 mip → 하늘 베일) × hazeK × φ_unresolved.
- **G_f(새 고운 물)**: 따로 하얀 베일 φ_f로 더한다(군집 사이 틈의 하얀 바탕).
- 셀 방울 위에는 그리지 않는다(기존 scat × (1 − cov)).
- 조기 종료: G_f + G_c ≈ 0인 픽셀.

### 3.5 비용 (추정, 1080p)
- 아틀라스 1–2(교차 구간만 2) + 장면 1 + 큐브 1 표본, ALU 소량 → **+0.06–0.10 ms**. 기존 평평한 산란 식은 이 경로로 대체된다.

## 4. haze 시뮬레이션 변경 (H3-b, H3-c)
### 4.1 두 성분 (HZ R16F → R16G16F, 2048 × 512, +2 MB)
- 공급 → **G_f**(SP0 / SP1의 고운 몫, 비 haze 몫).
- 조대화 G_f → G_c, 시간 τ_c(G_c가 있으면 빨라짐: 기존 방울이 고운 물을 흡수).
- 증발: 둘 다, 고운 쪽이 빠름(∝ 1/a²).
- 닦임 / halo(N2): 둘 다 같은 r2SweepFrac 가중 → cells 흡수와 질량 일치 유지.
- 상한: G_c ≤ G(a_max)(조대화 끝 = 셀 방울 크기 물량).

### 4.2 셀 방울 탄생 (N1 / N1b와 결합)
- 핵생성은 **a_eff ≥ a_max**인 곳만, 탄생 크기 ≥ a_max(작은 방울은 아틀라스가 맡는다 → 셀 격자의 작은 방울 자체가 없어짐).
- 자리: N1 결함 자리. 율속(셀 확률 상한, 넘친 만큼 크기 증가) + 고갈대 억제(N1b).
- 제거량은 hzm 비율로 haze 패스와 공유(기존 구조).

## 2.4 반경 범위 규칙 (2026-11-12, 사용자 질문: rmax 0.5는 실험값인가?)
- 0.5 mm는 다양성을 보려고 넓게 잡은 실험값이었다. 규칙으로 바꾼다.
- 자기유사라서 절대 크기는 런타임 옥타브가 정한다. 굽기에서 의미 있는 것은 **범위 비(최대 / 중앙)**와 **최대 조각 ≤ a_max** 두 가지다.
- 잘라내기는 방울을 키우지 않으므로 **rmax = a_max(0.3 mm)**로 그리면 최상위 옥타브(축척 1)에서 어떤 조각도 셀 방울 경계를 넘지 않는다(핵생성 임계와 일치).
- 지수 α 1.5: 조각 r p10 0.025 / p50 0.07 / p90 0.20 / 최대 0.29 mm, 덮임 0.75(12.8 mm 시험 굽기). 사진의 0.05–0.3 mm 범위와 맞는다.

|rmax|α|p50|p90|최대|p90 / p50|최대 / p50|
|---|---|---|---|---|---|---|
|0.12|2.2|0.039|0.080|0.120|2.1|3.1|
|0.2|1.5|0.058|0.135|0.200|2.3|3.4|
|**0.3**|**1.5**|**0.071**|**0.197**|**0.293**|**2.8**|**4.2**|
|0.5|2.2|0.052|0.227|0.490|4.3|9.4|
- 0.5 / 2.2(이전 값)는 최대 / 중앙이 9.4라, 큰 조각을 a_max에 맞추면 중앙값이 너무 작아진다.
- 기본값을 rmax 0.3, α 1.5로 바꿨다. 옥타브 기준 a_atlas = 조각 p50(0.07 mm); 최상위 옥타브 = G_c ≈ 4.8 G_sat. 그 위 초과량은 셀 방울로 핵생성된다.

## 3.5b 방울과 베일의 배타 규칙 (사용자 결정 2026-11-12)
- 요구: 방울 패턴이 나타나는 동안 **뿌연 베일과 방울이 같은 위치에 공존하지 않는다.** 방울이 된 구역은 클리어하게, 베일 없이.
- 물리: 방울은 자기 아래와 테두리에 닿는 미세 캡 / 새 고운 물을 흡수한다(breath figure 고갈대).
- 합성(visor):
  - D = w_det × vis(분해된 조각 덮임).
  - 틈 베일 V = 1 − (1 − U)(1 − φ_f), U = (1 − w_det)·φ(분해 안 된 캡), φ_f = 새 고운 물.
  - 지역 고갈: V ← V × saturate(1 − 1.3·D_loc), D_loc = 조각 덮임의 ~0.25 mm 이웃 평균.
  - 출력 = (장면·(1 − V) + 주변광·V)·(1 − D) + 방울색·D. **조각 위에는 베일이 전혀 없다.**
- 결과(`docs/prototypes/rainfx2_h3_exclusive_veil.png`, 이전 / 이후 2배 확대): 방울이 된 구역은 또렷하고 대비가 살아나며, 아직 고운 단계인 구역만 하얗다. 전환 중에는 '맑은 군집 구역'과 '하얀 구역'이 나란히 놓인다(겹치지 않음).
- 비용: D_loc는 visor에서 아틀라스의 한 단계 위 mip 덮임으로 얻는다(추가 표본 0–1).

## 8e. 닦인 뒤 재성장 점검 (2026-11-13, 코드 검토 / 수치, 게임 측정 전)
### 질문
닦인 haze가 0에서 다시 자라는가, 아니면 닦이기 전 모습이 곧바로 다시 나타나는가(빠른 성장인가, 이전 값의 재출현인가)?

### 점검 결과
1. **물량 G는 실제로 0에서 다시 시작한다.** haze 패스는 쓸린 몫을 제거한다(gMM·(1 − sweep), halo 안쪽 w = 1 → 0). cells가 같은 함수로 그 물을 가져간다. 이전 값을 기억하는 상태(채널 / 캐시)는 없다. 그 뒤 매 프레임 공급(분무 고운 몫 + 비 haze 몫) × 노출 × dt가 더해진다.
2. **그런데 화면은 '이전 모습의 재출현'이 된다** — 세 가지가 겹친다.
   - (a) **패턴이 고정이다.** 아틀라스는 바이저 좌표에 고정이고 조각은 순위 순서로 나타난다. 같은 G로 돌아오면 **같은 자리, 같은 조각**이 같은 순서로 다시 나온다(결정적).
   - (b) **크기가 재성장 이력과 무관하다.** a_eff = a_min·max(1, G/G_sat)·2^bias — 미리보기 바이어스를 켜면 조각이 처음부터 닦이기 전 크기로 나온다. 바이어스 없이도 상한(2 G_sat) 때문에 옥타브가 거의 바뀌지 않는다. 즉 '작은 방울 → 큰 방울' 단계가 없다.
   - (c) **덮임이 빨리 찬다.** φ(G)는 오목해서 조각의 60 %가 G = 0.5 G_sat에서 이미 나타난다(0.1 → 14 %, 0.3 → 39 %, 0.5 → 60 %, 1.0 → 100 %). G_sat = 0.0038 mm.
     - 공급 0.01 mm/s(고속 추종 분무 수준 추정) → 0.19 s에 60 %, 0.38 s에 포화 = '순간'.
     - 0.002 mm/s → 0.95 / 1.9 s. 비만(1e-4 mm/s) → 19 / 38 s.
3. 결론: 물리량은 0에서 재성장하지만, **표현이 '같은 패턴의 덮임 비율'만 되돌리고 크기 진화가 없어서** 고속 분무에서는 이전 모습이 즉시 재출현하는 것처럼 보인다. 바이어스 미리보기에서는 특히 그렇다.

### 타당한 재성장(물리)
- 1단계 고운 침착(분해 안 됨, 하얀 베일) → 2단계 덮임 포화 + 합체로 조대화(평균 크기 ∝ 쌓인 물, 수는 감소) → 3단계 큰 방울 사이 빈 곳에 새 세대.
- 닦인 자국은 주변과 다른 세대(더 작은 방울)로 한동안 구분되어 보인다(실제 바이저의 닦인 길).

### 제안(H3-3에 포함)
- **E1 크기는 이력(G_c)으로:** 두 성분 haze(§4.1). 닦이면 G_f, G_c 모두 0. 공급은 G_f로만 → 하얀 베일(고운 단계). G_c는 전환으로만 자란다 → 옥타브(a_eff ∝ G_c)가 0에서 다시 커진다 = 작은 방울에서 큰 방울로. 바이어스는 디버그 전용으로 둔다.
- **E2 덮임이 이끄는 조대화:** 전환율 = G_f / τ_c × (φ_f / φ_max)²(방울끼리 닿을 확률 ∝ 덮임²). 고정 τ 대신 규칙으로 → 공급이 클수록 빨리 조대화, 닦인 직후엔 느리게.
- **E3 세대(epoch):** HZ에 세대 값 하나를 더 둔다(RGBA16F: G_f, G_c, epoch). 닦인(sweep > 0.5) 텍셀은 새 세대 → visor가 세대 해시로 순위를 섞는다(rank' = frac(rank + hash(epoch))). 같은 G로 돌아와도 **다른 조각 집합**이 나타난다. 닦인 길의 가장자리에서 세대가 갈려 이음선이 생기지만, 그곳은 실제로도 닦인 자국 경계다.
- 비용: HZ 2 → 8 바이트 / 텍셀(2048 × 512, +6 MB), haze 패스 쓰기 1회 증가, visor 표본 동일(같은 텍스처의 채널) → 무시할 만하다.
- 검증: 공급 고정 상태에서 닦은 뒤 t = 0.1 / 0.5 / 2 / 5 s 연속 캡처(하얀 → 고운 군집 → 굵은 군집), 세대 이음선 확인.

### 남은 반투명의 원인과 H3-2c
- 화면은 DLSS 내부 1620 × 912 → 바이저 화소가 ~0.1 mm다. 누적이 약한 구간의 조각(반경 수십 µm)은 **화소보다 작다.** 그 조각들을 mip 평균 덮임의 문턱으로 그리니 부분 덮임(반투명 노이즈)이 됐다. 누적이 강하면 조각이 화소보다 커져 또렷했다(리뷰와 일치).
- 수정: **조각은 '또렷하게 그리거나, 아예 그리지 않거나'.**
  - 아틀라스 A = 크기순 면적 누적 순위(큰 조각 먼저; 틈은 가장 가까운 조각의 순위). 반경(순위) ≈ r_max(1 − 순위)^q, q 0.50.
  - 분해 한계 순위 A_res = 1 − (r_min / (r_max·s))^(1/q), r_min = resPx(기본 1 px) × max(화소, 2 CoC). 존재 조건 순위 < min(덮임 몫, A_res) → 화소보다 작은 조각은 그려지지 않고 그 물은 베일로 남는다.
  - 아틀라스 B = 조각 윤곽까지의 부호 거리(±0.1 mm). 가장자리 = 거리 / 화소 크기 → 어떤 배율에서도 1 px로 또렷하다(mip 덮임 미사용).
- **조각 halo(요청 2):** 존재하는 조각의 윤곽 바깥 halo(기본 0.5 × a_eff) 안은 베일 0. 같은 부호 거리 표본을 쓰므로 추가 표본이 없다(오히려 지역 덮임 표본 2개 제거).

### H3-3 구현(E1 / E2 반영, E3 보류)
- HZ = R16G16F: R = G_f(새 고운 물, 하얀 베일), G = G_c(조대화된 물 = 조각). 닦임 / halo는 둘 다 제거하고 cells는 둘의 합을 흡수(질량 일치).
- **E1:** 크기는 G_c만으로(a_eff = a_min·max(G_c / G_sat, 1), 옥타브 기준은 면적 중앙 반경 a50 0.212 mm; 최상위 옥타브 G_top = 14 G_sat ≈ 0.054 mm). 닦이면 0 / 0에서 하얀 베일 → 작은 조각 → 큰 조각으로 다시 진화한다.
- **E2:** 전환 G_f → G_c 율 = G_f / τ × (φ_f / φ_max)²(τ 기본 0.5 s). **개선:** 조각 위에 떨어진 공급(조각 덮임 몫)은 곧바로 G_c로 간다 → 조각이 덮인 구역은 틈에만 고운 물이 쌓인다.
- 증발: 고운 물 gR2FineEvapK, 조대화된 물은 × (a_min / a_eff)².
- **E3(세대) 보류 — 평가 결과:** 세대 경계가 haze 텍셀(0.29 mm) 계단으로 조각을 잘라 '방울이 아닌 것'을 그리게 된다. 순위를 크기순으로 바꾼 것과도 충돌한다. E1 / E2로 재성장이 옥타브(서로 다른 회전 / 오프셋 패턴)를 거치므로 즉시 재출현은 없어진다. 최종 상태가 같은 패턴으로 수렴하는 점이 거슬리면 조각 중심 벡터를 굽는 방식(텍스처 1장 추가)으로 다시 제안한다.
- **셀 방울 탄생(격자 대책, N1b 포함):** 셀의 G_c 초과량(G_top 위)이 a_max(0.3 mm) 방울 부피(shapeK·a_max³) 이상일 때만 사건. 사건 확률 상한 0.02 / 셀·프레임(UI), 결함 자리 가중 유지, 방울은 초과량의 60–100 %를 가져간다. 작은 방울은 아틀라스 조각이 맡으므로 '작은 방울의 셀 격자'가 사라진다. 이웃 억제는 새 방울의 halo 흡수가 맡는다(명시적 이웃 검사는 생략).
- 예상 시간(공급 0.01 mm/s): 하얀 베일 포화 ~0.4 s → 첫 조각 분해 ~1.5–2 s → 최상위 ~5.5 s → 셀 방울 탄생 ~7.5 s 이후.
- 지켜볼 점: haze가 품는 물이 늘어(최대 ~0.1 mm) 지나가는 셀 방울이 더 빨리 커진다.
- 비용: haze 패스에 `sweep ≥ 1` 조기 종료 추가(H3-P3). HZ 2 → 4 바이트 / 텍셀.

## 8h. 리뷰 4 → 반투명 / halo의 실제 원인 (2026-11-13, `docs/tools/rainfx2_h3_visor_micro_check.py`)
### 사용자 리뷰

2. **φ_U(분해 안 된 조대화된 물) 0.04–0.28:** 화소 0.1 mm(DLSS 내부 해상도)에서 반경 < 2 px(0.2 mm) 조각은 그리지 않고 **흰 산란**으로 넣었다. 하지만 0.1–0.2 mm 캡은 렌즈다. 대부분의 빛을 ±20° 안으로 굴절시키므로 화소 안에서는 **주변 장면의 평균(흐린 장면)**이 되고, 넓은 각도로 흩어지는 몫은 가장자리 일부(~30 %)뿐이다. 하늘색 베일이 아니다.
3. 결과: 강한 구간일수록 φ_U가 커져 '강할수록 하얗다'. 레퍼런스(사용자 사진)의 '맑은 미세 군집'과 반대 방향.

### 굴절 이질감 진단
- 셀 방울: **평볼록 물리 렌즈**(평평한 접촉면으로 들어가 캡으로 나감, n 1.333). 한 장면 상, 화면 밖은 화면 가장자리로 연속 압축, 전반사는 같은 상을 어둡게. 큐브맵 없음. 상은 뒤집혀 아래쪽에 하늘(초승달).
- 미세층(H3-3b): **필름의 얇은 프리즘 규칙**(기울기 방향으로 0.333·기울기 오프셋), 가파른 림은 **큐브맵 환경 × 0.7** + 반사, 장면 mip +1 고정.
  - 상의 방향 / 크기가 셀 방울과 다르다(뒤집힘 없음).
  - 림 색이 장면이 아닌 큐브맵에서 온다(회색 / 하늘색 테).
  - 작은 렌즈의 축소된 상에 맞는 흐림(mip)이 아니다.
- 같은 화면에서 두 종류의 '물'이 다른 광학을 써서 이질감이 생긴다.

### 제안
- **R1 미세 조각 = 셀 방울과 같은 평볼록 렌즈.** 같은 굴절식(Vo, 화면 투영, 연속 압축, 전반사)을 미분 없이 쓴다. mip은 조각 크기에서(작은 렌즈 = 축소된 상 = 흐림: mip ≈ log2(굴절 상의 화면 폭 / 조각 화소 폭)). 큐브맵 제거. 비용: 조각 화소에서만 장면 표본 1 → 3(r2Scene 홀 채움), 추정 +0.02–0.04 ms.

## 8k. 고속 분무에서 흐른 자리의 흰색 / 시트 위 haze 점검 (2026-11-13)

### 결과 1: 닦기 자체는 바닥값이 없다

### 결과 4: 시트는 haze를 닦지 않는다 (결함)
- haze 패스는 필드(B 시트 / film, R 실개울)를 읽지 않는다 → 시트 아래 G가 그대로 남고 분무 공급도 계속 받는다.
- visor는 scat *= (1 − microD)(1 − cov)만 하고 시트 덮임(covS)은 빼지 않는다. 게다가 평평한 시트는 covS가 꺼지므로(P2e) 그 자리에는 haze 베일이 그대로 그려진다 → 시트가 흰 베일 '안에 덧댄' 모양이 된다.
- 물리: 미세 캡(≤ 0.02 mm)은 물층(≥ 0.02–0.1 mm)에 닿으면 즉시 합쳐지고, 그 위에 떨어진 파편도 물층에 합쳐진다. 흰 베일은 마른 / 방울형 표면에서만 생긴다.

### 수정 제안
- **T1 (프레임 단위 → substep 단위 닦기 마스크):**
  - 셀 해상도 WM 패스를 substep마다 돌린다. 셀당 4×4 haze 텍셀 × 4 bit sweep, RGBA32F x / y / z에 24 bit씩.
  - 그 substep의 짧은 구간(≤ 1.95 셀 → 5×5 창으로 항상 완전)으로 계산하고, 이전 substep 마스크와 1 − Π(1 − s)로 합친다.
  - haze 패스는 후보 루프 대신 마스크 1회 Load. hzm은 비트 계산이 빠지고 nucleus / exposure / class만 남는다.
  - cells 흡수: 프레임 1회를 유지하되 창에 잘린 경로 길이로 보정한다(질량 오차 ≪ 방울 부피).
  - 예상 비용: WM 0.03–0.05 ms × substeps, haze −0.05–0.1, hzm −0.01 → 순증 ~0–0.1 ms.
- **S1 (물층이 haze를 흡수):**
  - haze 패스가 F_prev를 한 번 샘플한다.
  - 물 깊이 h_w = B·filmMax + R·trailMax ≥ gR2HazeWetMM(제안: sheetWetMM 0.02, 시트 꺼짐이면 filmMinMM)이거나 r2Wet 표면이면 G_f, G_c → 0, 공급도 0으로 둔다. 미세 분무는 rev48-F1부터 필드가 아닌 haze로만 가므로, 물층 위 공급분은 필드 패스가 같은 조건에서 B에 더한다(질량 보존).
  - visor는 같은 프레임 일치를 위해 scat *= 1 − covS0(P2e 전의 시트 덮임)을 적용한다.
  - 비용 ~0.01–0.02 ms.

## 8l. 흰 막으로 가는 공급 점검 → I1 충돌 라멜라 수거 (2026-11-13)
사용자 관찰(레퍼런스):
- 극단적 분무에서는 흰 막이 빠르게 차는 장면이 실제로 있다.
- 그래도 바이저 전체가 강한 흰색으로 유지되지는 않는다. 흰 막은 여러 농도가 섞여 있고(닦임 / 쌓임 주기가 느려 구역 차이가 생김) 더 젖은 느낌이다.
- 지금은 wetness 20 %에서도 흰 막이 대부분을 덮어 드라이한 느낌이 너무 강하다.

### 진단
도구: `docs/tools/rainfx2_h3_impact_sweep_check.py`, `rainfx2_h3_chase_sim.lua` 변형 'i1'.
- 분무 질량 분할(W.impactKeep, 분무 DSD):

|속도|부착|미세(G_f)|조대 < a_max|셀 방울|튀어 나감|
|---|---|---|---|---|---|
|200 km/h|0.26|0.04|0.05|0.17|0.74|
|240 km/h|0.26|0.08|0.04|0.14|0.74|

- 240 km/h의 분무 유량은 Rain 189, Thunderstorm 302, Heavy Rain 652 mm/h(바이저 정면)이다. 이 유량이면 각 충돌이 β_max·d(Roisman 2009, β ≈ 4, 중앙값 63 µm → 지름 ~0.26 mm) 라멜라로 퍼지면서 바이저의 모든 점을 **초당 10–36번(240 km/h), 2–12번(200 km/h)** 덮는다(nA = 유량 × ΣA / ΣV, 단위 부피당 라멜라 면적 150–200 /mm).
- 지금 모델은 이 라멜라를 무시한다. 미세 캡은 서로 닿을 때(E2, φ²)에만 합쳐진다 → 계속 들어오는 미세 파편이 마른 표면의 15 µm 캡 막(흰색)으로 그대로 쌓인다.
- 물리: 라멜라는 그 아래 캡을 쓸어 담아 자기 잔류물과 합친다(물에 닿은 물은 합쳐진다). 미세 캡 막은 nA 주기로 계속 갈아엎어져 더 큰 조각(G_c)이 된다. 정상 상태 G_f* = 미세 공급 / nA = 미세 비율 × V / A ≈ 0.07–0.11 G_sat(φF ≈ 0.02–0.04) — 세기와 무관하게 낮다. 남는 백색은 해상도 아래 조대 물(φU)뿐이고, 이것은 V2가 흐린 장면으로 그린다.

### I1 규칙

## 8r. V5 가우시안 산란광 (2026-11-16)

- **veil.hlsl, 두 패스(draw의 prepareSource에서 소스 밉 다음):**
