# E1 primary 반사 필터링

## 관찰과 방향

캡처 갱신과 낮/밤 하이라이트는 동작한다. 투영 공간 추적 개선으로 러버밴드의 갈라짐은 완화되었으나 프레임·패브릭·얼굴·발라클라바에서도 반복된 띠와 작은 히트/미스 틈이 남았다. 모든 반사 대상에 공통 처리를 적용한다.

현재 경로는 각 픽셀에서 첫 승인된 교차점 하나를 사용한다. 시간 누적이나 다중 반사는 없다. 단일 깊이 캡처에 없는 면은 복원할 수 없으며, 화면만으로 겹침의 모든 원인을 확정하지 않는다.

## 현재 구현

- 투영된 소스 화면 길이 기준으로 추적하며 원근 보정으로 광선 거리를 복원한다. 목표 간격은 소스 2픽셀이고 샘플 예산이 최대 단계 수를 제한한다.
- 깊이 캡처 G 채널에 메쉬 종류를 기록한다: 프레임 1, 러버 2, 패브릭 3, 얼굴 4, 발라클라바 5. 선형 깊이 보간과 교차 구간 이분 탐색은 같은 종류 안에서만 허용한다. 서로 다른 대상 사이의 가짜 교차를 차단한다. 같은 메쉬 내부의 깊이 불연속은 여전히 제한 사항이다.
- 즉시 히트 허용 오차는 0.25mm이며, 교차 구간은 8회 이분 탐색 후 2mm 이내 잔차를 검사한다. 휘도 gate는 픽셀 미분 폭을 최소 soft knee로 사용한다.
- lit/final에서 추적 결과를 현재 메인 카메라의 HDR 버퍼에 한 번 렌더링한다. 반사 RGB에 coverage/gate/Fresnel/gain을 적용한 후 9탭 공간 필터로 합성한다. 소스 이미지 블러에 더해 최종 히트/미스 틈과 색상 앨리어싱을 처리한다.
- 버퍼 알파에 INT 표면 거리를 저장한다. 메인 합성 시 해당 거리와 비교해 앞면 반사 결과가 겹친 뒷면에 다시 더해지는 것을 제한한다. 빈 픽셀 주변에서 밝기가 증폭되지 않도록 coverage로 재정규화하지 않는다.
- 현재 프레임만 사용한다. 실패하거나 갱신이 대기 상태이면 이전 반사 버퍼를 재사용하지 않는다. INT의 화면 투영으로 합성하며 EXT/COATING UV를 공유하지 않는다.

새 기본값은 source quality **2**, sample budget **32**, reflection-space blur **1.5px**, trace scale **0.75**이다. 저장된 settings_mats.ini 값은 유지된다. `Primary reflection-space blur`를 0으로 설정하면 기존 직접 추적 경로로 비교할 수 있다. trace scale은 선형 해상도 비율이며 0.75에서는 추적 픽셀 수가 원본의 56.25%가 된다. 필터와 HDR 버퍼 비용을 포함한 실제 이득은 게임에서 측정해야 한다.

## 사용자 측정: 이번 공간 필터 추가 전

기준 57.1 FPS = 17.51ms. FPS 차이와 프레임 시간 증가는 아래와 같다.

| Source quality | Sample budget | 결과 FPS | FPS 감소 | 프레임 시간 증가 |
|---|---|---|---|---|
| 3 | 256 | 38.9 | 18.2 | 8.19ms |
| 3 | 32 | 50.7 | 6.4 | 2.21ms |
| 2 | 256 | 41.2 | 15.9 | 6.76ms |
| 2 | 32 | 52.2 | 4.9 | 1.64ms |
| 1 | 256 | 47.6 | 9.5 | 3.50ms |
| 1 | 32 | 52.7 | 4.4 | 1.46ms |

사용자 평가: quality 1 이하에서는 곡선 단절 등 질적 저하가 크고 추가 비용 이득이 작다. quality 2 / budget 32와 블러 조합을 기준으로 검증한다. 샘플 예산 증가가 가장 큰 비용이다.

## 확인 범위

`docs/tools/check_e1_primary_shader.py`: 실제 inline HLSL의 primary·resolve를 FXC ps_5_0로 컴파일하고 강한 원근 변화에서 추적 거리 순서·양끝점·투영 간격을 검사한다.

`docs/tools/check_e1_resolve.py`: LuaJIT 전체 구문, 기존 네이티브 캡처 수명주기, 현재 프레임 추적, 이동 카메라 갱신, 해상도 변경, 오류/대기 후 정리, 메쉬 가시성 복원, blur 0 우회를 검사한다.

실제 게임에서 모든 반사 대상의 갈라짐, 경계 부드러움, 카메라 이동 시 갱신, DLSS 상태와 FPS를 확인해야 한다. 이 필터는 누락된 소스 면이나 심한 깊이 불연속을 복원하지 못한다.
