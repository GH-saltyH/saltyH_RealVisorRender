# E1 reference notes: superseded

There is no working E1 baseline. The user confirmed that all prior E1 attempts
failed visually; earlier success descriptions were mistaken. All previous E1
optical features were removed. Stage 1 passed user visual evaluation on 2026-10-08. An isolated stage 2
internal housing source preview is now available (E1_STAGE2_TEST.md). Stage 2 source isolation has passed user visual evaluation. Stage 3 now
adds a directional primary prototype; its visible reflection awaits evaluation.
There is no ghost path. After a gradient-only visual result, actual capture
matrices and source-depth origin parallax were added; game evaluation is pending. A separate stage 1 surface-output diagnostic is
documented in E1_STAGE1_TEST.md; it does not implement reflection.

The recovered ksPerPixelMultiMap_emissive source remains useful for studying
reflection, Fresnel, specular and lighting conventions. It is reference data,
not a project dependency or a proven replacement for internal visor optics.

See E1_OPTICAL_DESIGN.md for the new design and E1_RESTART.md for reset status.
