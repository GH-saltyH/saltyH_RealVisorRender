# 머티리얼 설정 저장

앱 폴더의 `settings_mats.ini`를 사용한다. 파일이 없으면 KN5 초기화 후 읽을 수 있는 현재 재질 값과 커스텀 기본값으로 생성한다. 초기화 순서는 KN5 로드 → 머티리얼 에디터 값 읽기 → 프로필 적용 → 저장된 머티리얼 값 복원/적용이다.

- `[MESH:메쉬이름]`: `MATERIAL_EDITORS.parameters`에 선언된 네이티브 float/bool/vec2/vec3 값을 저장한다. 복원/명시적 적용 시 메쉬 재질을 분리해 공유 재질의 다른 메쉬가 함께 바뀌지 않도록 한다.
- `[CUSTOM_SHADER]`: 커스텀 머티리얼 에디터가 참조하는 공유 `RAIN_VISOR_LAYER_*` 런타임 값을 저장한다. 공유 값은 한 번 저장하며 각 메쉬가 자신의 UV와 설정 키를 그대로 사용한다. 기존 네이티브 경로 고정 및 보류된 BVH 보호는 그대로 적용된다.
- 읽기에 실패한 재질의 기본 0값은 저장/자동 적용하지 않는다. 직접 편집한 값은 저장 가능하다. 잘못된 값은 복원하지 않고 현재 KN5/런타임 값을 유지한다.
- 없는 메쉬의 기존 섹션은 삭제하지 않는다. 이후 해당 메쉬가 포함된 KN5를 로드하면 적용한다.

네이티브 에디터의 `Refresh`/Enter는 값을 적용하고 저장한다. 커스텀 에디터 값 변경은 0.5초 후 자동 저장한다. KN5 탭과 머티리얼 창의 `Apply & save all materials`는 모든 편집값을 적용하고 저장한다. 기존 `Reload from material`은 현재 메쉬 값 다시 읽기이며 파일 초기화가 아니다. 메쉬 Visible은 기존 `settings.ini` 프로필에서 관리한다. RainFX 탭의 별도 설정은 이번 머티리얼 파일에 포함하지 않는다.

재로드/종료 시 대기 중인 커스텀 설정도 저장한다. 파일 쓰기는 CSP의 임시 파일 후 교체 옵션을 사용한다.

KN5 파일 자체를 변경하지 않으며 게임에서 재로드 적용은 별도 확인이 필요하다.
