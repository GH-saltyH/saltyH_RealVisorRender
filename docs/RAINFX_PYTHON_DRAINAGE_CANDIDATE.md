# 실제 재고 기반 첫 배출·재배분 후보 평가

2026-10-25. 사용자가 Python 원본 이미지와 게임 관찰의 형태가 같다고 확인한 뒤,
같은 초기 재고·메쉬·광학으로 후보 하나를 평가했다. **현재 후보는 게임에 채택하지 않았다.**

## 구현 범위

- 기존 deposit+drying baseline에 없는 물 이동을 표준 1차 donor-cell 수송으로 구현했다.
- 중력/관성과 공기 전단의 준정상 얇은 수막 속도 근사를 사용한다. 실제 du/dv와
  캡처 자세를 통해 세계 힘을 UV 운동으로 투영한다. 이것은 기존 SI head 운동을 대체하지 않는다.
- CFL 총 유출 비율을 substep마다0.8 이하로 제한하고,32Hz 구간을 두 번 나눈다.
  더 많은 정밀 substep을 늘려 통과시키는 연구는 하지 않았다.
- 이동하는 film과 같은 유출 비율의 micro를 entrain해 film으로 옮기는 근사를 추가했다.
  이 근사는 물을 더하지 않지만 현상별 계량은 아직 안 됐다.
- UV 외곽/invalid 이웃으로 간 물은 runoff로 기록한다. 실제 물리 외곽과 메쉬 seam의
  구분은 아직 검증하지 않았다. 물리 경계 구분 없이 제품으로 채택하지 않는다.
- 첫 경우는 중력만, 둘째는 캡처한 순간의 관성·공기력을10초간 고정한다. 두 경우 모두
  새 공급은 OFF이며, 방울/head는 진전시키거나 그리지 않는다. 미래 리플레이의 재현이나
  약한/강한 비 전체 장면이 아니다. 두꺼운 film/미세 물의 해소를 먼저 구분한 평가다.

## 결과와 판단

초기 field 물은21698.97mm³다.10초 후 중력 경우15505.86mm³,
캡처 힘 경우13818.60mm³가 남았고, 나머지는 runoff/증발로 기록됐다.
총 물량 오차는 두 경우 모두 약1.1e-11mm³ 이하였다. 이는 offline float64 결과이며
제품 FP32 GPU 검증을 대신하지 않는다. 음수 물 없음, 영속도 identity, 알려진 한 셀
flux/micro 전환, 네 방향/CFL, 열린 경계 검사는 통과했다.

그림에서 시야는 일부 회복된다. 하지만10초 후 최대 film 높이가 중력 경우약137mm,
캡처 힘 경우약830mm에 이른다. 일부 수렴 구역에 체적이 몰리며 얇은 수막 근사의
범위를 크게 벗어났다. CFL 제한은 이 잘못된 상태에서 요구 속도를 대부분 잘라낸다.
그림이 맑아졌다는 이유만으로 이 운동이 현실적이라고 받아들일 수 없다.
`transport.json`에 p99·10mm 초과 체적·요구 Courant·제한 비율도 남긴다.
캡처 힘10초 경우10mm 초과 셀에 약11628mm³가 몰렸다. 남은 field 물13819mm³의
대부분이어서, 화면 밖 한 셀의 무시 가능한 극값으로 취급하지 않는다.

**제품 채택 보류 이유는 미세한 수치 차이가 아니라, 수십 cm의 물을 연속 수막으로
취급하는 물리적 분류 결함이다.** 10mm 표시는 이번 오류의 규모를 드러내는 지표이며,
모든 최종 장면에 적용할 새 정밀도 통과 기준을 만든 것이 아니다.

다음은 solver 정밀도나 substep 증가가 아니다. 기존 local pool→drop 발상처럼
얇은 film과 두꺼운 고임을 구분하고, 초과 체적의 방울 전환/실제 배출을 같은 재고에
연결하는 최소 처리가 필요하다. 복잡한 전체 P4 수송/ABI 연구를 선행 조건으로
재개하지 않는다. head/film 출력 배율 및 연속 표시 과제도 남는다.

## 비용과 근거

- 후보1개, 실제 게임 요청0회, 게임 코드 변경0개. 첫 두 시나리오 총20초 CPU 계산은
  약47.5초였다. GPU 성능이나2048/4096 전체 앱 FPS를 추정한 수치가 아니다.
- 메모리/패스/GPU native 구현은 채택 조건을 통과하지 못해 추가 개발하지 않았다.
- 구현 전30–60분 범위를 기록했고 완료 시간은 `work_ledger.json`에 남긴다.
- 재현: `docs/tools/render_rain_product.py --drainage`.
- 결과: `docs/diagnostics/2026-10-25/python_drainage_candidate/transport_comparison.png`,
  `transport.json`, 각10초 film/micro NPZ. 이미지에 NOT ADOPTED를 표시한다.
- 원본 기준 이미지와 실패 자료는 보존하며, 이 후보 결과로 덮어쓰지 않는다.
