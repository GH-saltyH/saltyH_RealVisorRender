[독립 CSP 설계](../../RAINFX_CSP_REDESIGN.md)다. 새 렌더러는 아직 구현하지 않았다.

기존 앱과 연속 P0, 실제 실행 의존 모듈, 설치 자산, 레퍼런스 영상 표본 및 최신 실패
증거는 남겼다. P0의 기존 fault가 해결됐다는 의미는 아니다. SDK·모델 작업 폴더와
사용자 원본 영상은 삭제 대상에 포함하지 않았다.

## 복구와 정확한 목록

- [plan.json](plan.json): 삭제 대상별 원래 크기와 보관 여부.
- [report.json](report.json): 적용 결과, 현재 복구 ZIP SHA256 및 검증 결과.
- [installed_apps.json](installed_apps.json): 별도 설치 진단 앱의 정확한 경로와 복구 ZIP SHA256.
- [runtime_dependencies.json](../runtime_dependencies.json): 현재 보존한 Lua 의존 파일.

프로젝트 루트의 `archive/2026-10-25_legacy_research.zip`에 제거한 작성 소스·작은 보고서,
변경 전 메인/안내 문서와 이번 정리 스크립트를 보관했다. 별도 설치 앱 원본은
`archive/2026-10-25_installed_probe_apps.zip`에 보관했다. 두 ZIP은 CRC 검사를 통과했다.
대형 재생성 dump·컴파일 산출물은 전부 보관한 것이 아니다.

**archive 폴더는 Git 제외 대상이다. 커밋·push로 이 ZIP들이 보존되지 않으므로 별도로
보관해야 한다.** 복구할 때는 ZIP을 별도 폴더에 풀어 필요한 소스만 검토한다. 현재 앱
위에 전체 덮어쓰기를 하지 않는다. 보관본 안의 과거 설치 스크립트도 자동 실행하지 않는다.
